# Revive Adserver — Learnings

Append new discoveries, gotchas, and tips here as they emerge from real usage.
**2026-05-17**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — XML-RPC v2 API (11 services + Logon at /api/v2/xmlrpc/) and all hosted pricing tiers (Lite $10/1M, Plus $20/2M, Premium $50/5M, Super $100/10M, Ultimate $150/15M, Elite $175/mo min; overage $20/1M then $10/1M on Ultimate+) UNCHANGED. Drift fixed: v6.0.x now requires PHP 8.1+ (tested through PHP 8.5), not "PHP 8.0+"; v5.4.0+ supports up to PHP 8.1, v5.3.0+ up to PHP 8.0; latest release is v6.0.6 (March 2026, v6.0.0 launched Oct 2025); v6.0 added a new Mailer plugin (SMTP/3rd-party outbound mail), banner upload size limit, mixed-content warning; official requirements are MySQL 4.1+/PostgreSQL 8.1+ and any FastCGI server (Apache/Nginx/IIS7+/lighttpd/FrankenPHP). Third-party REST API plugin price corrected from "~$49+" to US$249/yr or US$599 lifetime, now compatible with v6.x. Still no webhooks, no MCP, no Zapier/Make in core Revive.

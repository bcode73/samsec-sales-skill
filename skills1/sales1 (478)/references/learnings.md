**2026-05-10**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. Pricing moved from pure pay-per-post ($3 comment / $6 post, 30-day full-refund "warranty") to a hybrid model: $79/mo (or $699/yr) subscription unlocking AI features + pay-as-you-go $4/comment & $8/post, with a 70% refund ($2.80 / $7) on a single removal check (24h comments, 48h posts) and full refund only if posting never goes live; up to 3 products on Basic. API endpoints are now product-scoped: import is POST /api/products/{productId}/ai-comments/manual-import (body `imports[]` of `{url, reply?}`, max 10, omit `reply` for AI = 1 credit); approve is POST /api/products/{productId}/ai-comments/{commentId}/approve (body `scheduleType` immediate|peak_hours|custom + `customDateTime`); list is GET /api/products/{productId}/ai-comments (status preview|queue|posted, page/pageSize≤100, search, executionId, moderatorRemoved). Auth keys use `sk_` prefix. Comment object uses isApproved/isPosted/isDeleted booleans + suggestedReply, not a single status string. Rate limit 100 req/min unchanged. No webhooks (confirmed absent). 5-comments/day-per-account limit confirmed via ReplyAgent blog. Sources: https://www.replyagent.ai/pricing, https://www.replyagent.ai/docs, https://www.replyagent.ai/docs/api/import, https://www.replyagent.ai/docs/api/list, https://www.replyagent.ai/docs/api/approve, https://www.replyagent.ai/blog/reddit-comment-services-with-managed-accounts.

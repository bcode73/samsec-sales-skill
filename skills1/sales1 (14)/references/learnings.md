**2026-05-24**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — core unchanged (API v1.5.2 build 20260514, base https://api.adspeed.com/, XML-only, MD5 sig + [ID][Name] entity token, 600/hr + 2400/day/method limits, create & stats methods 50/day, no webhooks/JSON, pricing Premium 100 = 100K imps $9.95/mo, add-ons $60/$60/$100, 10-day trial / 30-day money-back / up to 20% prepay). Drift corrected in param names/values: AS.Zones.create & AS.Zone.edit use `descr` not `description`; AS.Zone.setRate uses `width`/`height`/`type` (not `dimensions`/`ratetype`); AS.Zone.addRestriction uses `compare` (not `comparison`) plus required `type` (continent/country/region/metro/city/startend/keyword/totalimp/monthimp) and `value`; AS.Zone.getBreakdownStats requires `subcategory=ad` + 50/day limit; AS.Ads.createBanner requires both `clickurl` and `imageurl` (no width/height, optional `weight`); enriched createVideo/createVASTWrapper/createHTML/createText required params; added `status` filter to Zones/Advertisers getList; optimizer values are none/click/revenue/conversion/CTR (no eCPM). Sources: https://www.adspeed.com/Knowledges/830/AdSpeed-API/AdSpeed-API-Overview.html, https://www.adspeed.com/Knowledges/1046/AdSpeed-API/Zone.html, https://www.adspeed.com/Knowledges/1047/AdSpeed-API/Ad.html, https://www.adspeed.com/Knowledges/1050/AdSpeed-API/Campaign.html, https://www.adspeed.com/Knowledges/1051/AdSpeed-API/Advertiser.html, https://www.adspeed.com/Knowledges/1045/AdSpeed-API/Publisher.html, https://www.adspeed.com/Knowledges/1049/AdSpeed-API/Website.html, https://www.adspeed.com/Plans.html.

**2026-04-16**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — only drift found was Wave's daily rate limit, now 10,000/day per token (was 1,000/day); fixed in SKILL.md API ranking and platforms-smb.md Wave section. Confirmed UNCHANGED: Fathom (base `api.fathom.ai/external/v1`, `X-Api-Key`, 60/min per-user, `RateLimit-*` headers), Fireflies (GraphQL, `x-hub-signature` SHA-256 HMAC, Free 50/day, Business/Enterprise 60/min), Gong (3/sec + 10k/day, 429 + Retry-After), Granola (`grn_` Bearer, 25 burst / 5 req-sec sustained = 300/min, Business-gated, no webhooks), HappyScribe (200 req/hr on transcription endpoint, per-order `webhook_url`), MeetGeek (regional EU/US endpoints with region-specific keys, team webhooks, MCP), tl;dv (still v1alpha1). UNVERIFIED: a third-party guide mentions an "Otter Connect API v2" but Otter's official help page returned 403 — left the existing Enterprise-only-beta framing unchanged. Sources: https://api.wave.co/, https://wave.co/updates/wave-developer-api, https://developers.fathom.ai/quickstart, https://docs.fireflies.ai/graphql-api/webhooks, https://help.gong.io/docs/receive-access-to-the-api, https://docs.granola.ai/introduction, https://dev.happyscribe.com/sections/general/, https://docs.meetgeek.ai/getting-started/introduction.
**2026-06-13**: Added Descript (descript.com) to platforms-smb.md (after Temi) + platforms.md comparison table — AI transcription + text-based audio/video editing (edit media by editing the transcript), filler-word removal, AI summaries, Overdub voice cloning, Business-tier video translation/dubbing. NOT a live meeting bot (no auto-join, no CRM intelligence) — it's a media editor with transcription, so it sits with the batch/upload transcription tools (Sonix/Temi/HappyScribe), not the note-taker bots. Pricing (verified 2026-06): Free $0 (60 min/mo), Hobbyist $16/mo annual ($24 monthly, 600 min), Creator $24/mo annual ($35 monthly, 1,800 min), Business $50/mo annual ($65 monthly, 2,400 min + video translation), Enterprise custom; plans gate on media minutes + AI credits, not features (except translation = Business+). API is BETA: Bearer token scoped to a Drive; import media by URL or signed upload (links expire ~3 hrs); export transcript as text/Markdown/HTML/RTF/DOCX with optional speaker labels/timecodes/markers; publish project returns a public link + time-limited signed mp4 (no direct local export endpoint); NO webhooks (poll-only) — `429 Too Many Requests` + `Retry-After`; status endpoint documented but not yet live. Descript also exposes "API + MCP" (drive it from an AI assistant). HubSpot integration is a publish destination, not CRM field sync. Sources: https://docs.descriptapi.com/, https://help.descript.com/hc/en-us/articles/43370311322509-Descript-API, https://www.descript.com/integrations, https://www.descript.com/pricing.

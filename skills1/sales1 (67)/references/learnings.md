**2026-03-31**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — drift found and fixed: EU instances use the `.braze.eu` domain (not `.braze.com`) and instance list corrected (US-01..US-08 + US-10, no US-09; added ID-01/JP-01/KR-01); `/users/track` limit is now 75 objects TOTAL combined (per-array 75/225-combined is legacy-only) at 3,000 req/3s; added `/users/track/bulk` (≤1,000 objects, 2MB); replaced the vague "250k/hour default" with the documented per-endpoint rate-limit table; added new endpoint groups — Email Lists/Addresses (`/email/status`, blocklist, hard-bounce/spam removal), Cloud Data Ingestion (`GET /cdi/integrations`, `POST /cdi/integrations/{id}/sync`, `GET .../job_sync_status`), iOS Live Activities (`/messages/live_activity/start|update`), and full SDK Authentication trio (create/primary/keys, up to 3 keys); expanded SDK list (Cordova, .NET MAUI/Xamarin, Expo). Transactional endpoint `/transactional/v1/campaigns/{id}/send` unchanged. Pricing left as-is: Braze publishes no public tier page (Core/Pro/Enterprise + MAU model are third-party-sourced only), so plan-gate claims were not altered.

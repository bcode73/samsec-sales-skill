**2026-04-11**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift: auth is now API keys (Bearer token, scoped) + OAuth (partners); token+secret Basic auth is now DEPRECATED. All Admin API endpoints are under a `/v2` prefix; customer ID path param is `merchant_id`; reward redeem/refund moved to `/v2/customers/{merchant_id}/claimed_rewards[...]` and available rewards to `/v2/customers/{merchant_id}/available_rewards`; webview session is `/v2/sites/{site_id}/webviews/sessions`. Pagination now documented (cursor or since_id+limit). Webhooks signed with `x-loyaltylion-hmac-sha256` (base64 SHA-256 HMAC, OAuth client secret or site secret), 200-within-5s ack, retries with backoff, subscription removed after 30 failures. Headless API is date-versioned (`2025-06`). Pricing unchanged (Classic $199/mo published; Advanced/Plus custom). Sources: https://developers.loyaltylion.com/api-reference/authentication/overview, https://developers.loyaltylion.com/api-reference/authentication/api-keys, https://developers.loyaltylion.com/api-reference/authentication/oauth, https://developers.loyaltylion.com/api-reference/pagination, https://developers.loyaltylion.com/api-reference/v2/webhooks/overview, https://developers.loyaltylion.com/llms.txt, https://loyaltylion.com/pricing.

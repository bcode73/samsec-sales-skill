**2026-06-29**: By **FastLine Media LLC** (the Beaver Builder Team). GitHub org `github.com/beaverbuilder` (~10 public repos) — used for the `github:` frontmatter. It is a **standalone drag-and-drop page builder**, NOT a Gutenberg block plugin — it builds pages as **Rows → Columns → Modules** in its own live front-end editor over any theme; output is clean/semantic HTML, NOT `wp-block-*` markup. Product family: Beaver Builder plugin (free **Lite** + paid), the **Beaver Builder Theme**, **Beaver Themer** (theme builder + dynamic data), **Assistant Pro** (cloud asset/template library).

**2026-06-29**: **Low lock-in is a real differentiator.** When you deactivate Beaver Builder, the *formatting* disappears but the **text content survives cleanly in the default WordPress editor** (it does NOT leave broken/"invalid" blocks like Gutenberg block plugins do). Use this as the positive contrast when a user worries about migration/lock-in. Caveat: shortcode-based modules + Themer dynamic layouts won't render without BB, so the site degrades gracefully but isn't fully styled.

**2026-06-29**: **Pricing (best-effort, annual, 30-day refund):** Starter $89 (1 site), Plus $179 (3 sites), Professional $299 (50 sites), Unlimited $546 (unlimited). **Themer + Loop Builder + WooCommerce support now ship on ALL paid tiers** (a change from older "Themer is a paid add-on" guidance — confirm). **Multisite = Professional+**; **White Labeling = Unlimited-only**. Free **Lite** (WordPress.org) = reduced module set, no Themer/templates. Staging/dev sites never count toward site limits. Affiliate: **25% recurring, 30-day cookie**, ~$100 payout threshold, PayPal monthly.

**2026-06-29**: **Developer API** (the standout for makers/GTM engineers): custom modules **extend `FLBuilderModule`** (constructor sets name/description/group/category/dir/url/icon/editor_export/enabled/partial_refresh/include_wrapper), registered via **`FLBuilder::register_module( 'Class', $tabs )`** where `$tabs` = tabs → sections → fields (field types: text, textarea, photo, video, color, link, select, unit, dimension, icon…). Include behind a `class_exists( 'FLBuilder' )` guard; use a **prefixed dash-separated slug** to avoid core-module collisions. Large **`fl_builder_*` hooks/filters** surface (e.g. `fl_builder_subscribe_form_services`, `fl_builder_module_attributes`, `fl_builder_custom_fields`, `fl_builder_render_css`, `fl_builder_register_module`, `*_custom_class`). Searchable **Hooks Reference** at hooks.wpbeaverbuilder.com covers core + BB Theme + Beaver Themer.

**2026-06-29**: **No hosted REST API, no outbound webhook, no native A/B testing/heatmaps/cart/email.** Automation surface = WordPress core (WP REST API, application passwords, WP-CLI, WP_Query) + the PHP module/hooks API. A page's layout is stored in **`post_content`** (rendered HTML) + **`_fl_builder_data`** post meta (**serialized PHP** node tree of rows/columns/modules — internal, undocumented; parse server-side, don't hand-build). For event-driven flows, hook `save_post`/`publish_page` and POST yourself, or use a form plugin's webhook. Lead capture = the **Subscribe Form** module (ESP integrations like Mailchimp; extend via `fl_builder_subscribe_form_services`).

**2026-06-29**: **Beaver Themer + Field Connections** is the dynamic-data engine — bind any row/column/module setting (via the **+ icon**) to WordPress data, custom fields, **ACF**, Easy Digital Downloads, The Events Calendar, BigCommerce, or **WooCommerce**; a Themer layout then acts as a template across all matching posts/products. The **Loop Builder** renders dynamic listings. There's also a field-connection **shortcode syntax** for use outside the picker.

**2026-06-29**: Top support/community pain points (cover in Troubleshooting/Gotchas): (1) **builder deactivated on all pages except the home page after a migration** → serialized-data mismatch; fix with a serialized-safe **search-replace** (WP-CLI `search-replace --all-tables`/migration plugin) + clear cache + re-save; (2) **"not working after upgrading"** → cache/stale-CSS or plugin/theme conflict after a WP/BB/theme update → update BB+Themer+Theme together, clear caches, re-save, raise PHP memory, isolate conflicts; (3) **slow pages / sluggish editor on big layouts** → clean markup ≠ auto-fast; optimize images, add caching/minification, split long pages, audit theme/scripts.

**2026-06-29**: Positioning vs competitors — "freelancers start with it, agencies never outgrow it." The **stability + clean-markup + agency-handoff** pick. Competitors: Elementor (most templates/installs), Divi (lifetime/unlimited budget pick), **Bricks** (performance/dev pick, in backlog), **Breakdance** + **Oxygen** (added to backlog this run), SeedProd (WP landing-page plugin), and the Gutenberg block plugins (Kadence/Spectra/GenerateBlocks/Stackable/Nexter/Greenshift) for leanest output. Large third-party add-on ecosystem (PowerPack, Ultimate Addons for Beaver Builder) all built on the `FLBuilderModule` API.

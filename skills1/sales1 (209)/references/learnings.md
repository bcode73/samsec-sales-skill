**2026-04-17**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift fixed: transcript endpoint is `POST /v2/calls/transcript` (callId/date in body filter, scope `api:calls:read:transcript`), NOT `POST /v2/calls/{id}/transcript`; added `POST /v2/calls/extensive` for rich call content; the "~1,000 requests/hour" rate-limit tier is fabricated — Gong publishes only 3/sec + 10,000/day (low concurrency ceiling, raise via Gong support form); corrected CRM endpoints to the generic CRM API (`/v2/crm/integrations`, `/v2/crm/object/schema`, `/v2/crm/object/entities`, `api:crm:upload`/`api:crm:schema`) — `/v2/crm/object` and `/v2/crm/map-fields` were wrong; corrected Engage flow endpoints (`GET /v2/flows`, `/v2/flows/folders`, `/v2/flows/prospects`, `/v2/flows/prospects/assign`, two unassign endpoints, `api:flows:write`) — no `POST /v2/flows`/`PUT /v2/flows/{id}`; users stats are via `/v2/stats/*` not `/v2/users/{id}/stats`, added `POST /v2/users/extensive`; base URL is org/region-specific (read from API authentication page); scopes are granular (`api:calls:read:basic/transcript/extensive`); MCP is "coming soon, rolling June 2026" (client/gateway + server), not yet GA. Webhook payload (callData+isTest, 6 sections, JWT signing via public key) verified UNCHANGED. Pricing unverified (Gong publishes none; market-reported figures left intact).

**2026-03-29**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant endpoint-path drift corrected across email/search/contacts/companies/lists. Live OpenAPI shows V2 email at `/v2/email-finder` & `/v2/email-verifier` (snake_case full_name/first_name/last_name/domain/company params, envelope response), V1 email at `/public/v1/email/{find,verify,lookup}` (find uses `name`+`company`), B2B database search at `POST /public/v1/insights/{contacts,companies}` (pageSize/pageNumber/sort/order query + filter-object body) and `GET /public/v1/insights/contact?linkedinUrl=`, fast-search at `/api/v1/insights/search/fast-search/{search}`; workspace CRUD at `/api/v1/contacts/contact/{contactId}`, `/api/v1/companies/company/{companyId}` (+ `/search/query?name=`), lists at `/api/v1/contacts/lists` with add via `/{list}/add` body `contactsIds`; create-contact body is a `properties` array of `{property,value}` items. Auth = `apiKey` header (confirmed unchanged). No webhooks and no numeric rate limit documented (429 enumerated in error schema). "Under development" disclaimer no longer present. Pricing left unchanged — official /pricing is JS-rendered/403 and could not be authoritatively re-fetched.

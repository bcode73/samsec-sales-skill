**2026-06-13**: API re-verified against live official docs — V3 auth (platform.tealiumapis.com, 30-min JWT), Collect HTTP API (100 events/sec, HTTP 429, 10 events/bulk, global+regional hosts, 204 on integration endpoint), Visitor Profile API (live + historical lookups, 150-attribute max), and Visitor Privacy API (GET/DELETE/transaction/ids) all UNCHANGED; connector retry logic (1/5/30 min, codes 408/429/500/502/503/504, 5000ms timeout, 40%/20% overload throttle) UNCHANGED. NEW: iQ Profiles API is now a V3 product at /v3/tiq/accounts/{account}/profiles/{profile} (GET + PATCH; sub-APIs for variables/tags/load rules/JS extensions/events/tag templates) — previously iQ config was V2-only; added a regional integration/webhook Collect endpoint. Tealium still publishes no official pricing (custom, event/MUV-based), so the ~$149/mo entry figure remains unverified by official sources.

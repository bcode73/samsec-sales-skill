**2026-05-17**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — CORRECTED AUTH: it is MD5, not HMAC-SHA256 — analytics/management hash = MD5(MD5(password)+timestamp), sign-up hash = MD5(username+password+email+privateKey+timestamp); auth params (username/hash/timestamp) are URL PATH segments and REST endpoints end in `.do` (e.g. /rest-api/analytics/{format}/{username}/{hash}/{timestamp}.do), timestamp is UNIX MILLISECONDS not seconds; analytics query params are range/customFrom/customTo/groupBy/statisticType/groupRange/limit/offset (not dateFrom/dateTo/metrics), formats HTML/CSV/PDF/XLSX/JSON (XLSX not XLS), pagination via limit/offset. CORRECTED PRICING: Ad Server tiers now Light from $250/mo (8.5M display impr) / Growth from $1000/mo (40M) / Pro from $2500/mo (150M) / Enterprise custom, ~15% annual discount; white-label ($250/mo), premium support ($250/mo), advanced analytics ($500/mo) and SSP module ($0.001/1k requests) are PAID ADD-ONS, not bundled — earlier "white-label/RTB/support included on all plans" framing was wrong for the Ad Server (the REST API itself is still included on all plans). DSP unchanged (Light $250/Pro $2000/Enterprise custom, 5000 QPS, $500 setup). ads-api-v3 placement endpoint unchanged. UNVERIFIED: management endpoint exact paths beyond analytics/sign-up, JSON response shapes, rate limits, no-webhooks claim — left as-is. Sources: https://epom.com/pricing, https://help.epom.com/reference/get_analytics-format-username-hash-timestamp-do, https://help.epom.com/reference/post_user-sign-up-key-hash-timestamp-do, https://help.epom.com/reference/get_ads-api-v3, https://epom.com/pricing/dsp.

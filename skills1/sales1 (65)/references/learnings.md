**2026-05-04**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — pricing tiers (Starter $99/$89, Pro $299/$249, Expert $499/$399, Enterprise $1,299+/$1,099+) and core endpoints UNCHANGED, but: (1) API access now starts at Expert ($499/mo), NOT Enterprise-only — corrected everywhere; (2) callbacks/webhooks ARE documented — PostSearch & AddProject take a `callback` URL that gets a POST with search_hash/project_id (no HMAC) — the old "no webhook docs" gap was wrong; (3) PostSearch params are `keyword1..keyword5` + `match_type1` (exact/broad/case_sensitive) + `required_keywordsN[]`/`excluded_keywordsN[]` + `active_sources[]` + `languages[]`/`countries[]` + `stop_web_at`/`stop_social_at`, NOT `keywords[0]`/`sources`; (4) GetRemainingCredits returns `{"PostSearch","AddProject","Mentions"}` not `post_search_credits`; (5) search_hash returned as a number; (6) 78 error codes. Sources: https://api.brandmentions.com/documentation.html, https://brandmentions.com/pricing.php, https://help.brandmentions.com/en/articles/3585630-does-brandmentions-provide-api-access, https://help.brandmentions.com/en/articles/12814640-what-are-the-available-brandmentions-api-endpoints, https://help.brandmentions.com/en/articles/12814618-how-do-i-authenticate-api-requests-safely.

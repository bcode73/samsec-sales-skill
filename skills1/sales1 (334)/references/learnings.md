**2026-04-13**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — corrected several drifted items: OAuth token endpoint is on the reporting-instance host `https://{instance}.medallia.com/oauth/{company}/token` (company/tenant in path, NOT the gateway) with credentials in the HTTP Basic header (not the body) returning a Bearer token with expires_in:3600; gateway host is `{instance}-{company}.apis.medallia.com`; Import API lives under `/inbound/{version}/{importer-name}` and `/inbound/v2/async/{importer-name}` (async returns a feed file ID; detailed results show first 5,000 records per status) — the old `/admin/v1/import` paths were wrong (`/admin/v1/` is for Admin/Users/Roles APIs); rate limits add 10 calls/sec per API, a 3,000,000 cost-units-per-query Query API throttle, and draft-polli-ratelimit-headers HTTP headers; webhooks use a Webhook.Created event + X-Hook-Key header activation flow (POST .../hooks/{id}/activate) with OAuth2/Basic/shared-token outbound auth; MEC CLI install is `brew tap medallia/mec-cli && brew install mec` (repo medallia/mec-cli); added medallia/public-api-swaggers (OpenAPI specs). Query API endpoint `/data/v0/query` unchanged. Pricing unchanged (EDR-based, custom enterprise quote, no public rates — not re-confirmable from a public pricing page).

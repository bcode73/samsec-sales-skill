**2026-06-13**: API re-verified against live official docs — SIGNIFICANT pricing/feature drift. Pricing switched from results/month to CREDITS (charged per query by platform: Reddit/Twitter 2, TikTok 5, Instagram 12): Free now 5,000 credits ONE-TIME (was 100K results/mo), Pro $20/mo ($16 annual) / 30K credits, Max $200/mo ($160 annual) / 600K credits; overage now documented ($0.80 & $0.40 per 1K). Tracked items capped 1/10/30 (not unlimited); Premium Tools + Usage Analytics gated to Pro+ (skill wrongly said "no feature gating"). CSV export caps now tiered (Free 10K/500-per-file, Pro 50K/mo, Max 250K/mo; was flat 500K). TikTok now FULLY available (7 tools, was "coming soon"); Reddit now 9 tools (was 6, incl. subreddit search); Instagram 9 tools named; NEW tracking tools addTrackedItems/getTrackedItems/removeTrackedItems. MCP auth: API key (Authorization: Bearer header) now REQUIRED for Claude Code/Gemini CLI/n8n (no OAuth support) — skill wrongly said "no API key option for MCP"; key now at xpoz.ai/settings (not xpoz.ai/get-token). Still unverified: rate-limit numbers, per-tool param schemas, response JSON shapes.

**2026-06-13**: API re-verified against live official docs — webhook event list corrected and expanded to the full 29 events (member-update event is `member.edited`, NOT `member.updated`; added site/post/page/tag/post.tag/page.tag events); general Ghost webhooks have no HMAC/signature (the `whsec_` secret is Stripe-only); Admin API default content format is now **Lexical** (mobiledoc is legacy), `?formats=html,lexical` for HTML response and `?source=html` to create from HTML still valid; added Admin API **Labels** resource (Browse/Read/Edit/Add/Delete) and noted session-based user auth (email/password + 2FA) as a secondary auth method; pricing unchanged — Starter $15/mo annual ($18/mo monthly), Publisher $29, Business $199, paid subscriptions still gated to Publisher+; Content API unchanged (read-only, key query param, fully cacheable, no rate limit). Sources: https://ghost.org/pricing/, https://docs.ghost.org/admin-api, https://docs.ghost.org/content-api, https://docs.ghost.org/webhooks, https://docs.ghost.org/admin-api/posts, https://docs.ghost.org/admin-api/posts/creating-a-post, https://forum.ghost.org/t/updated-ghost-pro-pricing-july-2025-15-mo-starter-29-mo-publisher-199-mo-business/59090.

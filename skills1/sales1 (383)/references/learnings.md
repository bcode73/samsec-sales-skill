**2026-05-05**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — MAJOR drift: API is now v2 (`https://app.octolens.com/api/v2`), not v1. Mentions response is `{data, pagination:{nextCursor}}` (was `{mentions, cursor}`), mention fields are camelCase (`authorName`/`authorFollowers`/`relevanceScore`/`sourceId`). Big new endpoint surface: full keyword CRUD + suggestions, feeds CRUD (feeds replace "views"; pass feed id as `view`), filters, 4 analytics endpoints, members, feedback, `POST /ai/filter-wizard`, `GET /org/usage`, `POST /mentions/export` (up to 50K, JSON/CSV). API keys now carry scopes read/write/admin. Rate limit 500/hr is per-organization; 429 returns a `Retry-After` header and `X-RateLimit-Reset` is a Unix timestamp. Webhooks are per-feed with frequency (Instantly/Hourly/Daily/Weekly), payload is `{action:"mention_created", data:{...}}` (camelCase), still no signing. MCP v2 = OAuth, HTTP transport at `/api/mcp/v2` (no token to paste); v1 SSE `?token=` is legacy-only. Pricing UNCHANGED vs official page (Pro $119, Scale $319, Enterprise custom, 7-day/1K-mention trial, $0.007/mention + $5–10/keyword add-ons) — third-party sources (G2/ColdIQ) listing $149/$399 and a "Starter" plan are stale/inaccurate. Sources: https://octolens.com/docs/api/v2/overview, https://octolens.com/docs/api-reference/mentions/list-mentions, https://octolens.com/docs/api-reference/mentions/export-mentions, https://octolens.com/docs/api-reference/keywords/list-keywords, https://octolens.com/docs/api-reference/organization/get-usage-stats, https://octolens.com/docs/llms.txt, https://octolens.com/docs/quickstart/webhooks, https://octolens.com/docs/mcp/v2/overview, https://octolens.com/docs/mcp/v2/setup-guides, https://octolens.com/pricing.

**2026-04-24**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. (1) AUTH: real header names are `ClientID` / `ClientSecret` (apiKey, in:header) per OpenAPI securitySchemes, NOT `X-Client-Id`/`X-Client-Secret`; a JWT `Authorization: Bearer` alternative also exists. (2) PRICING: Palabra dropped the standalone API "Pro $150 / Scale $900 / Business $3,500" plans for a unified credit subscription with tiers Starter/Pro/Team/Business (Meetings product: $60/$200/$1,000/custom monthly; 150/900/3,500 credits); "Scale" tier removed; new API-captions credit rate (10/7/5 per hr) and tier-varying rates added. Talo meeting-app pricing ($33/$100/$500/Enterprise) UNCHANGED. (3) ENDPOINTS: per-voice paths are `/saas/voice/m/{voice_id}` (the `/m/` segment was missing); NEW endpoint families Event V2 (`/saas/v2/event*`) and Channels (`/saas/channel*`) added; new voice ops (`/tts-sample`, `/favorite`, `/hidden`); deprecated `POST /session-storage/sessions` and `GET /billing/balance` noted. (4) SDK: JS package is `@palabra-ai/translator` not `palabra-ai`; Python `palabra-ai` and env vars `PALABRA_CLIENT_ID`/`PALABRA_CLIENT_SECRET` UNCHANGED. No webhooks confirmed (none in spec). Sources: https://api.palabra.ai/docs/openapi.json, https://www.palabra.ai/pricing, https://docs.palabra.ai/, https://taloai.com/pricing, https://github.com/PalabraAI/palabra-ai-javascript, https://github.com/PalabraAI/palabra-ai-python.

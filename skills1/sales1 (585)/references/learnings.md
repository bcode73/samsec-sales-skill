**2026-04-26**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — SIGNIFICANT drift. Sybill now publishes a full public REST API (api.sybill.ai/docs, alpha): base `https://api.sybill.ai`, `Authorization: Bearer sk_live_...`, scopes read/ingest/ask_sybill, rate limits 60/min · 1,000/hr · 10,000/day, cursor pagination (limit/cursor, max 50), endpoints for /v1/conversations, /v1/deals, /v1/accounts, /v1/messages, /v1/rows, /v1/documents, /v1/sources, /v1/object-types, /v1/health — replacing the prior "no public API docs, Enterprise-only contract" claim (API+MCP access is still gated to Enterprise per pricing). MCP server at https://mcp.sybill.ai/mcp (OAuth, 8 tools). Webhooks are Pro+ (not Enterprise-only), single event `meeting.new_recording.v1`, delivered via Svix with HMAC signature verification + exponential-backoff retries — prior docs said no signing/standard POST. Pricing: Pro $30 annual / $36 monthly; Business $79 annual / $108 monthly (was listed flat at $90). Dialers Salesloft + Zoom Phone + Dialpad now native. Added references/sybill-api-reference.md. Sources: https://api.sybill.ai/docs/introduction.html, https://api.sybill.ai/docs/authentication.html, https://api.sybill.ai/docs/rate-limiting.html, https://api.sybill.ai/docs/pagination.html, https://api.sybill.ai/docs/endpoints.html, https://api.sybill.ai/docs/data-models.html, https://api.sybill.ai/docs/mcp.html, https://help.sybill.ai/en/articles/9925117-webhook-automations-with-sybill, https://www.sybill.ai/pricing, https://www.sybill.ai/integrations.

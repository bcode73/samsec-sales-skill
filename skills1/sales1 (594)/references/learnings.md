**2026-06-13**: API re-verified against live official docs — Modify-documents endpoints moved from `/api/v1/search/p/{project_id}/results/{update,delete,import}` to a v2 Documents API `/api/v2/docs/p/<project_id>/{create,update,upsert,delete,undelete}` (+ batch and `/d/<dataset_id>/` dataset variants); document create/update/delete now cost 0 credits and import requires the doc match a project topic. Streaming stream-creation and project-data-access endpoints have a documented 5 calls/min limit; stream rules use `rule_id`+`query` fields (not `q`/`lang`). Histogram costs 10 credits/call; credits reset monthly on the subscription day at 03:00 UTC; new Search param `custom_focus`; export blocklist now explicitly includes raw TikTok and FB/IG fully non-exportable.

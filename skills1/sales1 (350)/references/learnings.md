**2026-05-07**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. API is no longer read-only: OpenAPI spec now defines GET /me, GET/POST /keywords, PATCH /keywords/{id}, GET /mentions/{id}, PATCH /mentions/{id} (relevance feedback), GET /digest, POST /reply-drafts. Base URL is /api/v1; mention list returns a `pagination` object (page/limit/hasNext/hasPrev, no `total`) plus optional `redditLockedCount`. Mention object now uses `source`/`source_domain`/`matched_at` and embeds the keyword under `keywords` (dropped flat keyword_id, content_type, published_at, created_at; content_type survives as a query filter). New query params: `source` (enum firehose/reddit/brave/google_news/serper) and `contact_found`. Pricing tiers renamed: Starter→Monitor ($29, 5 keywords, 30-day history), Pro→Radar ($59, 20 keywords, 90-day history); both include webhook delivery, reply drafts, competitor share-of-voice. Free plan: not shown on /pricing but /me plan enum still lists `free` and some third-party listings cite a 1-keyword/7-day free tier — left as unverified. Webhooks remain a real feature (listed on paid tiers) but undocumented in the OpenAPI spec. Sources: https://www.mentiondrop.com/openapi/mentiondrop-v1.json, https://www.mentiondrop.com/docs/api, https://www.mentiondrop.com/pricing.

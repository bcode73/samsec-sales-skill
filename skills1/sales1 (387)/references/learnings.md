**2026-04-01**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift fixed: auth changed from `X-API-KEY` header to `Authorization: Omnisend-API-Key YOUR-API-KEY`; per-endpoint rate limits now documented (100/min lists, 15/min writes, 10/min + 55/day analytics) replacing the prior "undocumented" note; error `type` URI is now `https://problems.omnisend.com/…` with a `retryAfter` field; contact tags moved to batch endpoints `/contacts/tags` (POST/DELETE) and there is no individual `DELETE /contacts/{id}`; POST `/contacts` is an upsert and a `PATCH /contacts` update-by-email exists; product update uses PUT (not PATCH) and categories live at `/product-categories` (not `/categories`); events payload now nests a `contact` object and requires `origin` (recommended events also need `eventVersion`); Segments API now supports full CRUD (was read-only); webhooks confirmed as outbound automation action blocks on paid plans only; NEW MCP Server at mcp.omnisend.com/v2/mcp and llms.txt agent index. Pricing: SMS moved to volume-based add-on (~$0.007/SMS) on 4 May 2026 and Pro no longer bundles SMS credits = subscription price; Free web push capped at 500/mo (not unlimited). UNVERIFIED: webhook HMAC `x-omnisend-signature` (only in third-party guides); availability of legacy versions v3/v4.0; `/templates`, `/images`, `/brands`, `/reports` analytics paths (not re-confirmed individually).

**2026-06-13**: API re-verified against live official docs — minimal drift. All 4 APIs (REST/Surfaces/Metadata/Schema) unchanged: REST API still read-only (no POST/PUT), `/wp-json/yoast/v1/get_head?url=` + `yoast_head`/`yoast_head_json` fields intact (json format needs v16.7+), Surfaces API still 14.0+ with `open_graph_fb_app_id` deprecated since 15.5, all Metadata presenters and Schema filters confirmed. Pricing unchanged: Premium €118.80/yr, WooCommerce SEO €178.80/yr, AI+ €358.80/yr ($29.90/mo annual), Shopify $19/30 days, Google Docs add-on €5/mo (1 seat free with Premium). CORRECTED: AI+ is no longer just "extended AI content suggestions" — it is now the top "complete search visibility package" bundling WooCommerce SEO + AI Brand Insights (AI answer-engine brand monitoring across ChatGPT/Perplexity/Gemini, beta Oct 1 2025). NEW gotcha added: `wpseo_json_ld_output` filter disables `<head>` schema but does NOT strip schema from the `yoast_head_json` REST attribute (separate code path) — matters for headless.

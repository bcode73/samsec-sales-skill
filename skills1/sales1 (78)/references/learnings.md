**2026-05-10**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — major drift. Buzzabout now ships a PUBLIC REST API (base https://api.buzzabout.ai, all under /v1, auth `x-api-key: bz_live_...` NOT Bearer; JSON; cursor pagination limit/cursor/order max 100; discriminated `status` envelope; 5 req/s per-key limit shared with MCP via RateLimit-* headers + 429 retry_after_seconds; 402 insufficient_credits; 409 audience_dataset_run_already_in_flight; endpoint groups datasets/tracking-agents/audience-datasets/mentions/audience-profiles/pattern-detections/custom-parameters/ask/me; verified paths POST /v1/datasets, POST /v1/datasets/{id}/runs, GET /v1/datasets/{id}/runs/{run_id}, POST /v1/mentions) gated to the **Business** plan, plus a native **MCP server** at https://mcp.buzzabout.ai/mcp/ (OAuth or x-api-key, 15 read-only+ask tools, no CRUD) gated to **Pro**. Pricing model replaced "Research Hours" with monthly **credits** and per-seat tiers: Starter $50/$40yr (2,000 credits, 300 mentions/research, 1 seat, $0.025/credit overage), Pro $150/$100yr (10,000, 1,000, 5 seats, $0.02, +MCP), Business $350/$250yr (50,000, 1,000, unlimited seats, $0.015, +API), Enterprise custom (+custom data sources, dedicated CSM). Free trial = 500 credits over 3 days. Old skill claims corrected: API was 'Enterprise-only' (now Business+), overage was flat $0.25/RH (now tiered per-credit), 'Zapier webhook is the only automation path' (now webhook/Slack/email alerts on all plans + MCP on Pro + REST API on Business). UNVERIFIED: webhook payload schema + signing/HMAC, exact per-query credit cost, whether Zapier has a native app (pricing page lists generic 'Webhooks' only).

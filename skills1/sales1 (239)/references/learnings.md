this at the start of each invocation and appends new learnings as they're discovered.

**2026-07-04**: Research baseline — the validate-before-building methodology (evidence ladder: problem
research → ~10 behavior-focused interviews → AI validation → fake-door/smoke test → pre-sale/WTP), the
"AI idea score is not demand" caveat, the ~5%+ smoke-test conversion bar, and the AI-validator tool
landscape (Validator AI, DimeADozen, IdeaProof, aicofounder, FounderPal, WorthBuild, Trend Seeker)
captured from live sources on this date. Re-verify tool tiers and benchmarks before relying on them.

**2026-07-04**: The strongest cheap signal is money (a pre-sale / paid pilot), not a waitlist email —
weight evidence by how much commitment it costs the person (email < "buy" click < card entered). Set a
go/no-go threshold before running the test so a weak result can't be rationalized after the fact.

**2026-07-04**: AI idea validators ([[sales-validator-ai]] and peers) confidently hallucinate — two
tools disagree on the same idea, and an LLM will "validate" almost anything. Use them to sharpen the
pitch and surface competitors/objections, then cross-check with a real-behavior signal
([[sales-trendseeker]] for Reddit demand, or a landing-page smoke test via [[sales-funnel]]).

**2026-07-04**: "No competitors" is usually a demand red flag (no market / bad search), not a green
field — push the user to find how people solve the problem today (including spreadsheets and manual workarounds).

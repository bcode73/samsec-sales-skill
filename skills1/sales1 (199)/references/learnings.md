**2026-06-29**: Research baseline — platform docs, public hooks/filters, the dynamic-tag registration API, pricing, and integration surface captured from live sources on this date. generateblocks.com homepage is fetchable; `/pricing` 404s and `/pro` 301-redirects to generatepress.com/blocks/. learn.generatepress.com developer docs are bot-protected (403 to automated fetch) — the `generateblocks_dynamic_tag_output` signature came from search snippets + the SnippetClub 2.0 guide, not the primary page. Re-verify specifics against current docs before relying on them.

**2026-06-29**: By Tom Usborne / **EDGE22 Studios LTD** (@edge22 on WordPress.org) — same team as the **GeneratePress** theme. v2.3.0, 200,000+ active installs, tested to WP 7.0, PHP 7.2+. **No public GitHub org repo** (developed on WP.org SVN/Trac) — so no `github:` field in frontmatter.
**2026-06-29**: **GenerateBlocks 2.0 was a rewrite** (new Styles engine, unified Query Loop, Dynamic Tags). Block names/attributes changed from 1.x; the old Dynamic Data UI differs. Always confirm the version — pre-2.0 tutorials mislead.
**2026-06-29**: ~9 blocks by design (Container, Grid, Headline, Button, Image, Query Loop + sub-blocks). Container + Grid are layout primitives you compose into pricing tables/testimonials/etc. — there are no one-off widget blocks. This minimalism is the #1 "where's the X block?" confusion vs Kadence/Stackable (40+ blocks).
**2026-06-29**: Plan gates — **Free**: core blocks + Query Loop. **Pro** (Dynamic Data, Global Styles, 150+ templates/asset library, device visibility, shape dividers, gradients, scroll effects, custom attributes). Pricing best-effort: Pro Personal ~$59/yr (1 site), Pro Professional ~$99/yr (500 sites), GeneratePress One ~$149/yr bundle (GP Premium + GB Pro + GenerateCloud). Pro features can degrade/lose styling if the license lapses — test fallbacks on staging.
**2026-06-29**: Developer surface = WordPress core REST API (blocks are `generateblocks/`-namespaced in `post_content`) + PHP filters (`generateblocks_dynamic_tag_output`, `generateblocks_dynamic_content_output` (1.x), `generateblocks_image_url`, `generateblocks_dynamic_image_fallback`, `generateblocks_do_content`) + the `GenerateBlocks_Register_Dynamic_Tag` class (2.0+, register on `init`, callback returns via `GenerateBlocks_Dynamic_Tag_Callbacks::output()`). No hosted API, no webhook, no form block, no Zapier app.
**2026-06-29**: Performance is the whole pitch — leanest DOM/CSS of the major block plugins; pairs with GeneratePress for the lightest stack. If CWV is still bad, blame theme/images/third-party scripts first. Affiliate program: ~25% commission, 30-day cookie, $75 min payout, PayPal monthly (generateblocks.com/affiliates/).

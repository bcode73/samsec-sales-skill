**2026-06-13**: API re-verified against live official docs — the prior "no REST API / JavaScript-embed-only" framing was WRONG. SafetyMails now publishes (a) a custom HTTP REST real-time API `POST https://<TICKET_ORIGEM>.safetymails.com/api/<CODE_TICKET>` authed by `Sf-Hmac: HMAC_SHA256(email, API_Key)` header with form-data `email`, returning JSON `{Success, Email, Status, Score}` / error `{Success, ErrorCode, Message}`; (b) a batch validation API (list submit / job status / download results) via Swagger at panel.safetymails.com/swagger_api2.html, gated behind support-issued credentials; (c) an official SDK repo github.com/SafetyMails-Team/safetymails-sdk with JS/PHP/Python/Java/Go examples; (d) the standard script embed URL `optin.safetymails.com/main/safetyscript/<TICKET>/safetyoptin.js`. Pricing UNCHANGED (PAYG $7.50/1K, sub $6.80/mo, $68/yr, 100 free + 1,000 trial credits, 2M max, subscription required for API). Still undocumented: rate limits, webhooks, Email Finder programmatic API. One SDK example shows an unconfirmed alternate route `api.safetymails.com/v2/validation/email` with `apikey` header — left flagged, not asserted. Sources: https://github.com/SafetyMails-Team/safetymails-sdk, https://docs.safetymails.com/article/real-time-email-validation-api, https://www.safetymails.com/email-checker-api/, https://www.safetymails.com/email-verification-pricing/.

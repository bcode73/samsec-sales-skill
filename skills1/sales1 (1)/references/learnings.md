**2026-04-02**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. Docs are now PUBLIC at the api.6sense.com/docs API Portal and support.6sense.com/docs (was previously documented as auth-walled). People Enrichment moved from scribe.6sense.com/v2/people/Enrichment to POST api.6sense.com/v2/enrichment/people (batch ≤25 by peopleId/email/linkedinUrl, 20 q/s). Added Company Firmographics (POST api.6sense.com/v1/enrichment/company), Lead Scoring (POST scribe.6sense.com/v2/people/score, no credit cost), People Search (POST api.6sense.com/v2/search/people, no credit cost) + Search Dictionary (GET /v2/search/dictionary). Auth confirmed: 40-char alphanumeric token, Authorization: Token header, generated in Settings > Integration > API Token Management. Rate limits now documented (100 req/min general, 20 q/s People APIs, adjustable). Added error codes 402 Quota exhausted + 422 Validation. Credit model: Company ID = 1 credit/matched response (same-IP dedup within contract year); Enrichment APIs share a pool (same-record dedup within calendar month); People Search + Lead Scoring no-cost. AI Email API uses Saleswhale docs (docs.saleswhale.com) with webhooks. Company Identification GET epsilon.6sense.com/v3/company/details and Authorization: Token scheme UNCHANGED. Pricing UNCHANGED (Free $0/50 credits; enterprise custom ~$50K-$300K/yr, median ~$55K via Vendr). Sources: https://api.6sense.com/docs/, https://support.6sense.com/docs/6sense-api-overview.md, https://support.6sense.com/docs/api-credits-api-tokens, https://6sense.com/platform/people-company-api/, https://www.vendr.com/marketplace/6sense.

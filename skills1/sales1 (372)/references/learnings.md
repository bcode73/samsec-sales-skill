**2026-06-29**: Research baseline — platform docs, pricing, the Nexter Abilities (MCP) page, and the integration surface captured from live sources on this date. nexterwp.com homepage/pricing/nexter-abilities render to WebFetch (a clean Markdown copy is published at nexterwp.com/nexter-abilities.md); the GitHub repo (`posimyth/the-plus-addons-for-block-editor`) README documents no hooks or block namespace; docs.nexterwp.com portal exists (Nexter Blocks 305 articles, Builder 49, Extension 82) but is end-user-oriented. **2026-06-29**: Made by **POSIMYTH Innovations** (also makes The Plus Addons for Elementor, WDesignKit, UiChemy, SproutUI), **GPLv3**, WordPress.org slug `the-plus-addons-for-block-editor` (formerly "The Plus Addons for Block Editor" / "The Plus Blocks for Gutenberg"). ~10,000+ active installs, 4.8★ (89 reviews), v4.7.x, tested to WP 7.0, PHP 7.4+ — actively maintained. **v4.7.0 converted all blocks to WordPress ApiVersion 3** — treat as a migration boundary.

**2026-06-29**: Three parts — **Nexter Blocks** (90+ blocks, ~45 free/~45 Pro, in-editor AI via ChatGPT + Gemini, 1000+ templates), **Nexter Extension** (50+ site tools + **Theme Builder**, security/performance/code-snippets, White Label), **Nexter Theme** (lightweight, jQuery-free). Defining contrast vs Stackable/GenerateBlocks: Nexter **ships** a Form Builder (9 field types, login/registration/Mailchimp), Popup Builder (6 types), Mega Menu, and Header/Theme Builder.

**2026-06-29**: **Nexter Abilities = a native MCP server** (custom architecture, NOT the WordPress Abilities API) exposing **115 tools**: 68 free + 47 Pro blocks, 8 workflow skills, 5 button-preset CRUD, 1 page-inspection. Works with Claude Desktop/Cursor/VS Code/Windsurf/Cline/Zed/Continue. Token auth, scoped to post types + abilities, respects WP capabilities, toggle-off anytime. Performance "page-type budget" (image/font/animation caps) enforced before placing blocks. Can recreate from a screenshot or inspect a URL. The endpoint path/config snippet/token are generated per-site — NOT captured verbatim.

**2026-06-29**: No hosted REST API and no native webhook — it's a WordPress plugin. Programmatic surface = the **MCP server** + WP core REST API (block markup is **`tpgb/`-namespaced** in `post_content` — best-effort, consistent with `tpgb_*` option flags) + PHP option flags (`default_tpgb_load_opt`, `tpgb_defer_css_js`, `tpgb_delay_css_js`). **Do NOT invent `tpgb_*` hooks or the namespace** — confirm against a live install.

**2026-06-29**: Pricing best-effort/annual with Lifetime options (60-day money-back): Yearly **Starter $39 (1 site) / Professional $89 (5 sites, +Theme Builder +White Label) / Studio $129 (unlimited)**; Lifetime $139/$249/$349; **Agency Bundle $399/yr or $899 lifetime** (+ The Plus Addons for Elementor + WDesignKit). **Theme Builder & White Label = Professional+. Dynamic Content (ACF/Toolset/Pods), WooCommerce blocks, advanced popups, Lottie/Spline/scroll animations, GA4/Pixel blocks, and the 47 Pro MCP abilities = Pro.** Free tier includes 68 of the 115 MCP abilities. Affiliate up to ~$440+/sale.

**2026-06-29**: Top issues — (1) "blocks not showing" (not in Gutenberg Block Editor / Classic Editor or another builder active / plugin-JS conflict / stale build-cache); (2) **performance claims vs reality** (claims 1 CSS+1 JS/page + disabled blocks load nothing + zero jQuery; PluginTests still shows ~0.24–0.35s + ~6–9 MiB added — use `tpgb_defer_css_js`/`tpgb_delay_css_js`, enable only needed blocks, cache); (3) plan-gate surprises (Theme Builder/White Label = Professional+); (4) major-update regressions (esp. the v4.7.0 ApiVersion-3 conversion — back up + staging). No native A/B testing/heatmaps/analytics.

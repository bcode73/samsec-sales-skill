**2026-07-07**: Research baseline — platform positioning, pricing, and surface captured from live sources on this date (plansnack.com homepage, Slashdot, GoodFirms). Re-verify specifics against current docs before relying on them.

**2026-07-07**: PlanSnack is a **manual guided one-page template with pre-written examples, NOT an AI generator** — the single most common confusion is expecting it to write the plan for you (it doesn't) or to produce a fundable full plan with financials (one-page only, no forecasting). This is the primary disambiguation vs the AI-generator cluster (Bizplanr/Upmetrics/VentureKit/Plannit/BizPlanner AI/BizPlan AI Pro).

**2026-07-07**: **Aggregator discrepancy** — Slashdot/GoodFirms auto-populate feature tags (financial projections, collaboration, investor management, pitch presentation, dashboard) that PlanSnack's own homepage does NOT claim. Treat those as unverified; trust plansnack.com. Both directories showed "No User Reviews" (thin footprint) and support "business hours only," training "not offered."

**2026-07-07**: **Unconfirmed at research** — whether an account/signup is required to build/save/export, and the exact export file format (PDF vs Word). Homepage states "download, print, and share" are included and free ("no upgrades, no pro version, no credit card"), with vague "premium services" promised for the future but none live yet. Verify current state on the live site.

**2026-07-07**: **No public API, no webhooks, no Zapier/Make, no MCP, no integrations** (homepage "no integrations at this time"). Automation ceiling for programmatic plan text is "call an LLM API directly." Surfaced as an Upmetrics free alternative; sits under /sales-idea-validation.

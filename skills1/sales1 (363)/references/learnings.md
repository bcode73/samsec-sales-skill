**2026-05-16**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — base URL/query-param auth UNCHANGED, but corrected: all create/update calls use POST not PUT (campaigns, lists, subscribers, segments, custom fields); custom-field path is `customfields` (one word) not `custom_fields`; get-subscriber-by-id is `/subscribers/{list}/find/{id}.json` not `/{id}/view.json`; segment details/subscribers are `/segments/{id}/details.json` and `/segments/{id}/members.json`; collection pagination uses PATH segments `/lists/{Page}/{PageSize}.json` not query params; added unsubscribe variants (list+campaign, account-level), campaign schedule/unschedule/view_summary/view_ab_summary/stats/countries endpoints. Rate limits ARE NOW publicly documented per-resource (add 10/10s, subscribe_many 2/10s, unsubscribe 20/10s, remove 40/10s, transactional 6/1s; 429 returns `{"Code":429,"Error":"RATE-LIMITING"}`) — superseded old "not documented" note. Wrapper repos renamed to `api-wrappers-{php,java,dotnet,js}` (official JS wrapper now exists). Pricing ladder updated (500=~$9/mo, 1k=$16, 2k=$24, 5k=$48, 10k=$88; annual saves 20%, 6-mo saves 15%; one-off non-expiring email credits added). Still no signed webhooks (automation HTTP POST only); no automation API. Could NOT verify a delete-criteria segment endpoint — flagged as unverified.

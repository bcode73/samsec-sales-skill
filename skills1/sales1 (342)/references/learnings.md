**2026-04-11**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — confirmed drift fixed: (1) API now has v3 AND v4 (v4 being built out, "in time will support all features"); base URL is `https://api.meltwater.com` with `/v3/<feature>/...` paths, apikey header, HTTPS-only (unchanged). (2) Rate limits are NOW PUBLIC (skill said "not documented"): 100/min general, 2000/hr per IP, exports 20/min, earned-media analytics 5/sec+100/min, Mira 60/min. (3) Webhooks EXIST as "Data Streams"/"hooks" (skill said "not documented"): `POST/GET /v3/hooks`, `DELETE /v3/hooks/{hook_id}`, HMAC-SHA1 `X-Hub-Signature` (sha1= prefix) via `X-Hook-Secret` shared secret (16-64 chars), 5 retries/5-min delay/30s timeout, hook auto-deleted on persistent failure. (4) Mira chat is `POST /v3/mira/responses` (input[] messages, `streaming:true`, `Thread-Id` resp header, `Project-ID` req header) + `GET /v3/mira/projects`; MCP server is `https://api.meltwater.com/mcp` (apikey header, 60/min shared). (5) BYOC import is `POST /v3/imports/documents` (≤500/batch, unique id, dup→400, whole-batch validation) + `/imports/batches` & `/imports/import_tags`; actively updated through Jan 2026. Pricing left UNCHANGED — Meltwater publishes no official pricing (quote-only, annual), figures are third-party only and not editable from official sources.

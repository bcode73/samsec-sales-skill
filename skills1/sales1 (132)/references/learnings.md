**2026-06-29**: Research baseline — platform docs, API surface, pricing, and webhooks captured from fetchable sources on this date. ⚠️ The CustomCat homepage and `/pricing` page bot-block WebFetch (HTTP 403); research was assembled from the help center (`help.customcat.com`), the API docs (`customcat-beta.mylocker.net/api/v1/`), the Shopify app listing, and third-party reviews. Re-verify pricing against the live site. Key facts: budget US (Detroit) POD, in-house fulfillment, 1–3 business-day production (fastest of the big 3), US-only (international 1–4 weeks), **no private-label branding** (products keep manufacturer tags). 200+ products; decoration via DIGISOFT™ (DTG/DTF), embroidery, dye sublimation. Connectors: Shopify, Etsy, WooCommerce, BigCommerce (+ CSV). API base `https://customcat-beta.mylocker.net/api/v1/`; auth = API key in request (read-only + read-write); TLS required; **403 = read-only key on a write op**. Endpoints: catalog/catalogcategory/design/product/order (`POST/DELETE /order/{order_id}`, `GET /order/status/{order_id}`)/shipping/webhook. `order_id` is the idempotency key (`400 Duplicate Order` on re-use). Webhooks: 6 topics (`order-shipped`, `order-partial-shipment`, `product-created/-deleted/-updated`, `design-rejected`), **NOT HMAC-signed** — verify the echoed read-only `api_key` and keep a `/order/status` polling backup. `sandbox=1` for tests; AVS returns a `suggestions` array on bad US addresses; back print +$5/line item; design files 300 DPI; design `preset_id` placements. Pricing: Lite $0 (standard wholesale), Pro $30/mo or $300/yr ≈$25/mo (20–40% off, 60-day trial), Enterprise custom (30–50% off + custom API access). Affiliate program exists (monthly commission on product cost). No published rate limits. No notable public GitHub org/SDK found.

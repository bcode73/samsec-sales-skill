**2026-06-27**: Research baseline — platform docs, Paddle Billing API, pricing/fee model, and webhook signing captured from live sources on this date. Re-verify before relying. Key facts: Paddle is a **Merchant of Record (MoR)** — it's the legal seller and **calculates + remits global sales tax/VAT (300+ markets)**, so you don't build tax logic. **Two incompatible products: Paddle Classic (legacy) vs Paddle Billing (current)** — different base URLs, auth, schemas, webhooks; build on **Billing**. API: base `https://api.paddle.com` (sandbox `https://sandbox-api.paddle.com`, separate keys), **Bearer API key** from Paddle → Developer Tools → Authentication (set an expiry; client-side tokens for browser checkout are separate). REST GET/POST/PATCH; entities products/prices/discounts, customers/addresses/businesses, transactions/subscriptions/adjustments, events/notifications, reports. **Money is a string in the smallest unit** (cents) — `"2000"` = $20.00. Pagination via `meta.pagination.next` + `per_page`; `include` for related entities. **Webhooks signed HMAC-SHA256** (`Paddle-Signature: ts=...;h1=...`, sign `ts:rawbody`); events `subscription.created/activated/updated/canceled/paused/resumed/past_due`, `transaction.created/updated/billed/completed/payment_failed`, `customer.*`, `adjustment.created`. **Delivery order NOT guaranteed** — order by `occurred_at`; **idempotency via `event_id`** (Paddle redelivers). Official **Docs MCP** (docs retrieval for AI assistants, not an account-data API). Postman collection + sandbox. Fees (best-effort): **~5% + $0.50/transaction, all-inclusive** (global tax included) — same as Lemon Squeezy; Polar ~10%+$0.50; Stripe ~2.9%+$0.30 but NOT a MoR. GitHub org `PaddleHQ` (54 repos). No affiliate program confirmed. As MoR, Paddle controls payouts (scheduled) + enforces acceptable-use review.

**2026-06-13**: API re-verified against live official docs — V1 is now deprecated (V1 Swagger banner: "Modjo API V1 is deprecated. We recommend migrating to the latest version", pointing to api.modjo.ai/v2/docs); API V2 launched ~April 2026 and lets you query Accounts/Opportunities/Users/Tags and more with advanced filters; webhooks deliver `x-modjo-payload-signature` + `x-modjo-timestamp` HTTP headers (mirroring body fields), HMAC-SHA256 formula unchanged; calls/exports relation is `aiScoringResults` (not `scoring`) and returns `ApiV1CallExportPaginationResult` (201); auth (`X-API-KEY`), V1 endpoints/methods, event names, upload formats, and pricing (~€99/user/mo, listener licenses free, custom/annual, no free trial) all unchanged. V2 swagger.json requires auth (401 anonymous) so exact V2 paths/schemas not captured anonymously.

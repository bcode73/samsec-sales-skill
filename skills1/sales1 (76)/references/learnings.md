**2026-04-12**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — confirmed several drifts and added missing detail. (1) Subscriber-create field is now `email_address` (not `email`) and `type` (not `subscriber_type`), plus `ip_address` for spam-check — fixed code example. (2) Rate limits are concrete, not just "generous": 600 req/min globally (429 + Retry-After) and 100 subscriber-creates/day (returns 400 → use bulk import). (3) API is date-versioned via `X-API-Version` header, current `2026-04-01`. (4) Granular/multiple API keys since 2026-01-24; keys managed at buttondown.com/keys (API → Keys), not buttondown.com/requests. (5) Added full Events & webhooks coverage: event types (subscriber.created/confirmed/unsubscribed/opened/clicked/deleted, email.created/sent, comment.created), payload {event_type, data}, multi-event webhooks since 2024-10-29, HMAC-SHA256 signing via `X-Buttondown-Signature: sha256=<hmac>` over raw body, POST /v1/webhooks CRUD, no stable IPs. (6) CLI installs via `npm install -g @buttondown/cli` (login/pull/create/push), not just "GitHub buttondown/cli". (7) Pricing now pay-as-you-grow by active subscriber count; add-on à-la-carte model + Sponsorships (+$9/mo) confirmed + 50% non-profit discount confirmed; named per-tier prices (Basic/Standard/Professional/Advanced) NOT confirmable on the public page (requires entering subscriber count) — left as-is, flagged unverified. Unchanged: base URL https://api.buttondown.com/v1/, Token auth, Buttondown-Context header, 8 permission categories + write/read/none + 403, email statuses draft/scheduled/about_to_send, API on all plans incl. free. Sources: https://docs.buttondown.com/api-authentication, https://docs.buttondown.com/api-rate-limits, https://docs.buttondown.com/api-versioning, https://docs.buttondown.com/api-subscribers-create, https://docs.buttondown.com/events-and-webhooks-introduction, https://docs.buttondown.com/api-webhooks-create, https://docs.buttondown.com/api-webhooks-event-types, https://docs.buttondown.com/buttondown-cli, https://buttondown.com/pricing, https://buttondown.com/blog/2026-01-24-api-keys, https://buttondown.com/blog/webhook-examples, https://buttondown.com/changelog/2024-10-29.

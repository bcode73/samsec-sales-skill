**2026-03-30**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — corrected the validate rate limit (it's 80,000 requests per 10 seconds / 100,000 for ZeroBounce ONE™ with a 1-minute block, NOT 80,000/hour with a 24-hour block); fixed validate invalid-key response to {"error":"Invalid API Key or your account ran out of credits"} (getcredits still returns {"Credits":"-1"}); fixed AI Scoring scale from 1-10 to 0-10 (bulk CSV primary + a single real-time endpoint); fixed Pay-As-You-Go pricing (starts at $20 for 2,000 emails, not $39); documented the previously-gapped Email Finder endpoint GET /v2/guessformat (domain/company_name + name params, email_confidence HIGH/MEDIUM/LOW, 20 credits); added new Domain Search API (bulk host domain-search/sendfile|filestatus|getfile, 20 credits/result), AI Scoring bulk endpoints (scoring/sendFile|filestatus|getFile|deletefile, PHASE_1/PHASE_2/COMBINED downloads), validate response fields active_in_days + catchall_domain, ZeroBounce ONE annual ≈$79/mo, and the official MCP server @zerobounce/mcp; noted greylist webhooks live on a separate Greylist API (no documented HMAC signing) and that domain_info validate param + List Evaluator endpoint remain unverified.

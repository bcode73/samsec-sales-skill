**2026-04-18**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. Pricing moved to "Supernormal 2.0" credit-based plans: Free $0 (15/mo, 5/day), Team $20/mo (was "Pro", 50/mo, no daily limit, rollover, unlimited shared-credit seats), Business $40/mo (50/mo, +SSO/audit/data-retention/admin); seat-based pricing retired. Native HubSpot, Salesforce, Pipedrive, ClickUp, GitHub, Workable, Zapier, and Asana integrations were DISCONTINUED 2026-03-02 (agentic-model pivot) — native CRM sync no longer exists. MCP is now documented: server `https://api.supernormal.com/mcp`, auth via AI-tool connector, reads meetings/projects/action items; Linear is now an MCP integration. Current native integrations: Gmail, Google/Outlook Calendar, Google Drive, Slack. Still no public REST/GraphQL API and no documented webhooks. Legacy per-tier GPT-3.5/GPT-4 split no longer published. Sources: https://www.supernormal.com/pricing, https://help.supernormal.com/en/articles/14418695-supernormal-2-0-plans-pricing, https://help.supernormal.com/en/articles/14691492-is-supernormal-releasing-new-pricing, https://help.supernormal.com/en/articles/14484919-supernormal-mcp, https://help.supernormal.com/en/articles/13890833-how-and-why-is-supernormal-changing, https://www.supernormal.com/integrations, https://help.supernormal.com/en/articles/8563080-plans-pricing-legacy.

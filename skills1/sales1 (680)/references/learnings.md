**2026-06-13**: API re-verified against live official docs — significant drift. ZoomInfo's CURRENT developer API is the GTM API (base `https://api.zoominfo.com/gtm`) using OAuth 2.0 (Client Credentials / Auth Code+PKCE / Refresh Token, token endpoint `POST /gtm/oauth/v1/token`, short-lived ~1000s bearer token) — the old PKI/JWT `/authenticate` 60-min flow is now labeled "Legacy" at api-docs.zoominfo.com. Endpoints are pluralized/entity-first (`/gtm/data/v1/contacts/enrich`, `/gtm/data/v1/contacts/search`, etc.); pagination is `page[number]`/`page[size]` (max size 100, was 25/rpp); Usage is `GET /gtm/data/v1/users/current/usage`. Rate limits are 25/30/35 req/s (default/Premium/Premium+) and rate-limit headers are NOT returned (skill previously claimed X-RateLimit-* + 1/s auth + 33/s scaling — corrected). Bulk async-callback `/bulk/enrich` is not in current GTM docs (synchronous, 25 records/request) — moved to legacy section. NEW since baseline: webhooks now documented via Agent Teams (job-complete/record-change/credit-threshold/new-signal); official MCP server `https://mcp.zoominfo.com/mcp` with Claude Code support; developer portal `developer.zoominfo.com`; many new endpoints (enrich intent/news/scoops/org-charts/technologies, search intent/news/scoops, lookup, contact-recommendations, company-lookalikes, audiences, ICP segments). Pricing unchanged (Copilot is Elite ~$39,995/yr). Unverified/left as-is: exact webhook event-type strings + payload schema + signature header; WebSights/Compliance GTM endpoints (not in GTM index). SDK + MCP-plugin GitHub repos still live (200).

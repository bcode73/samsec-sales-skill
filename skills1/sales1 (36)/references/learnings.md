**2026-04-10**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — base URL (api.attio.com/v2), OAuth/Bearer auth, 100 reads/25 writes per sec, pricing (Free/$29/$69/Enterprise), and MCP (mcp.attio.com/mcp) all UNCHANGED. Corrected webhook event names: attribute.* is split into list-attribute.* and object-attribute.*; comment.updated removed in favor of comment.resolved/comment.unresolved; workspace-member.added → workspace-member.created; call-recording.completed → call-recording.created; added note-content.updated. Added webhook signing (Attio-Signature SHA256 HMAC, timing-safe), retry (10x over ~3 days, 5s timeout, 2xx success, Idempotency-Key, at-least-once). Added score-based rate limits for List records/entries (10s sliding window). Added Meetings (beta)/Call Recordings/Transcripts/Files/Workspaces/SCIM endpoint families. Corrected SDK claim: Attio has NO official REST client SDKs (only the official App SDK for embedded TS/React apps + community attio-js); the old 5-language official-SDK table was wrong. Sources: https://docs.attio.com/rest-api/guides/rate-limiting, https://docs.attio.com/rest-api/guides/webhooks, https://docs.attio.com/llms.txt, https://docs.attio.com/rest-api/overview, https://docs.attio.com/mcp/overview, https://attio.com/platform/developers, https://github.com/attio, https://docs.attio.com/rest-api/endpoint-reference/meetings/list-meetings.

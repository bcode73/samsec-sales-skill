**2026-06-13**: API re-verified against live official docs — minor drift. Latest release v6.1.0 (2026-03-29). Added new bounce webhook providers Forward Email (/webhooks/service/forwardemail) and Lettermint (/webhooks/service/lettermint, new in 6.1.0) plus the generic /webhooks/bounce endpoint; documented the full RBAC permission-scope list and the new campaigns:send permission (separate from campaigns:manage — required to start a send, returns 403 without it); corrected campaign status transitions (paused cannot go directly to cancelled — only running→cancelled/paused, paused/draft→running, scheduled→draft, draft→scheduled); noted v6.1.0 Privacy setting (disable view/click tracking) and S3 media proxying. Core API (auth BasicAuth/token, base URL, /api/subscribers, /api/lists, /api/campaigns, /api/tx with subscriber_mode default/fallback/external + altbody param, response {data:...}, error codes incl 429, no documented self-imposed rate limits) and license AGPLv3 + free/no-feature-gates pricing model all UNCHANGED.

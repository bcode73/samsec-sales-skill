**2026-04-24**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — minor drift. Pricing still Free / Pro $129.99/yr / Enterprise (no public REST API; webhook + Zapier "New Note V2" + Notion all Pro-gated). Corrections: Pro file limit is 6 hours/audio recording (not "3-hour"), 500 MB/file; webhook & Zapier payload is richer than the old 6-field set — also carries action-items array, tags, source type (voice/upload/YouTube/WhatsApp), and recording duration in seconds; webhooks have NO HMAC but DO support user-defined custom headers (e.g. Authorization/X-Api-Key) for sender verification — previous "no signature verification, fixed non-customizable payload" framing was wrong; Notion now supports per-note one-tap "Send to Notion" plus per-workspace auto-sync toggle and syncs action items + tags. Unverified/ambiguous across official pages (left unchanged): language count (homepage "80+" vs pricing page "99+"), a homepage reference to an "Ultra" plan not shown on the pricing page, and a third-party-only "Personal $69/yr" tier the official pricing page does NOT show.

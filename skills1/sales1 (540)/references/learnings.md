**2026-03-30**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. Campaign, prospect, sender-account, warmup, and CRM endpoints are now v2 resource-style routes (v1 campaign endpoints superseded); NEW endpoint families added: Email Accounts `/v2/sender-accounts/*`, Email Warmup `/v2/warm-up*`, CRM `/v2/pipelines*`, campaign email-step-content + schedules + recipients-activity-report. Balance endpoint is `POST /v1/user/balance` (was `/v1/check-user-balance`). Webhook update is `PUT /v1/webhooks` ("change status"). Email verifier `unknown_status_reason` now enumerates banned/catchall/connection_error/greylist/hidden_by_owner. Auth (OAuth client_credentials, 1h token), base URL, 60 req/min rate limit, and async POST-start/GET-result pattern all UNCHANGED. Pricing updated: Pro M $189 (20K credits), Pro L $369 (50K), top tier "Ultra" $738 (100K/200K recipients), separate "Custom" from 200K credits; Trial = 100 recipients + 1 warmup slot; LinkedIn add-on $69/slot free plan / $59 with paid plan (~$62 annual). Sources: https://snov.io/api, https://snov.io/knowledgebase/how-to-use-snov-io-api/, https://snov.io/pricing, https://snov.io/knowledgebase/pricing-plans-overview/, https://www.saleshandy.com/blog/snovio-pricing/.

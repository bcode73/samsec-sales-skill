**2026-03-30**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift corrected. Base URL is `https://api.skrapp.io` (was `skrapp.io/api`); finder/account/list endpoints use `/api/v2/...`, verifier uses `/v3/...` (no `/api/`). Endpoints are GET `/api/v2/find` (params firstName+lastName or fullName, plus company or domain; +pattern/quality response), POST `/api/v2/find_bulk` (max 100), GET `/v3/verify` (+enrich; email_status/mailbox_status/mailbox_type/mailbox_exchange), GET `/v3/verify_bulk` (max 50), GET `/api/v2/account` (credit quota/used), GET `/api/v2/list/:listId` and `/api/v2/list/:listId/leads` (start/size cursor, max size 500). Auth is HTTP Basic via `X-Access-Key` header — old POST `/emailFinder` `/emailVerifier` `/companyInfo` JSON-body paths are gone; standalone companyInfo endpoint not in current v2 docs (firmographics now via find's includeCompanyData). Pricing now USD: Free $0/50cr, Professional $29 annual/$39 monthly/2,000cr, Enterprise $262 annual/$349 monthly/50,000cr; API Integration is Enterprise-only (docs say "paid accounts" generically). Verifier status value is `catch-all` not `accept-all`; credits charged only on Valid/Catch-all finds (Fair Credit Policy), credits roll over. Company profiles now advertised 40M+ (was 20M+). No webhooks; rate limits still undocumented. Sources: https://skrapp.io/api, https://skrapp.io/pricing, https://skrapp.io/.

**2026-06-13**: API re-verified against live official docs — API surface UNCHANGED (base URL https://api.trendhero.io/api/public/v1, Bearer auth, POST /reports?username= + GET /reports/{username}, statuses collecting/recollecting/ready/impossibleButReady/impossible/preview, response keys preview/report/openai_report/saves_shares_report, webhook payload report_type/notification_type/account_pk/version all confirmed). NOT changed (could not verify against a rendered official page): pricing — the trendhero.io/pricing/ page is fully JS-rendered and unfetchable; third-party reviews + an official-domain search snippet suggest Lite ≈$9.99 / Pro ≈$29.99–39 / Advanced ≈$99.99–119.99 (vs the skill's $16/$40/$120), and annual-vs-monthly framing conflicts, so pricing is flagged stale-but-UNVERIFIED and left untouched. Tracking-account limits (Lite 3/Pro 20/Advanced 50) also left as-is: the only official page found (Tracking FAQ) lists "Lite 2 / Pro 20 / Advanced 50" but that is the limit for *removing* accounts from tracking, a different metric — do not conflate.

**2026-06-13**: API re-verified against live official docs — minor drift only. Confirmed unchanged: Basic+JWT auth (Okta/Entra ID), Premium Snap Pack Tier 1 +$45K / Tier 2 +$15K, 1,000+ Snaps, the 12 Public API categories. Corrected/added: Public API base path is `/api/1/rest/public` (not generic `/api/1/rest/...`); JWT header `Authorization: Bearer Token {token}` with required claims iat/exp/sub/aud/iss/org and `aud`=POD base URL (custom `snaplogic_aud` accepted); Basic header `Authorization: Basic {base64 <email>:<password>}`; added Runtime endpoint `/runtime/apistats/{org}` (+/daily,/concurrent); documented triggered-task rate limits (concurrent default 10, daily reset midnight UTC, HTTP 429) and API Policy Manager Client Throttling max 1000 calls/min; added SnapGPT audit-log Public API (45-day history). New since baseline: APIM 3.0 exposes pipelines as MCP services (MCP Server with OAuth2 Client Credentials + JWT Validator, Trusted Agent Identity, MCP Metrics in Monitor); AgentCreator 3.0; Google GenAI LLM Snap Pack; Cache Service GA + AI Gateway + JRE 17 support (May 2026 release).

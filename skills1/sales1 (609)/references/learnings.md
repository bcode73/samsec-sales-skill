**2026-06-13**: API re-verified against live official docs — no drift found. Base URL `https://pasta.tldv.io`, `x-api-key` auth, v1alpha1, all endpoints/methods, `/highlights` deprecated, transcript/notes field names, and webhook events (`MeetingReady`/`TranscriptReady`, User/Team/Org scopes, no HMAC signing) all confirmed unchanged. Added NEW evidence-backed webhook detail to api-reference: Settings→Webhooks config flow, HTTPS-only, optional custom headers, payload shape (id/event/executedAt/data). No documented rate limits. Sources: https://doc.tldv.io/index.html, https://intercom.help/tldv/en/articles/11583137-api-and-webhooks, https://intercom.help/tldv/en/articles/15416775-webhooks, https://www.claap.io/blog/tl-dv-pricing, https://github.com/tldv-public/tldv-mcp-server.

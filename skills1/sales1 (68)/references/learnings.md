**2026-06-29**: Research baseline — platform homepage, the developer docs (Form Actions API, Dynamic Data API, Conditions API, hooks, AI endpoints, reusable dependencies, Menu/Animations JS), the forms webhook/integration docs, pricing, and the Oxygen relationship captured from live sources on this date. breakdance.com homepage, /get (pricing), /documentation/developers/, and the github.com/soflyy/breakdance-developer-docs repo (default branch `master`, lowercase `readme.md` files) are all fetchable; raw README.md (capitalized) 404s. Re-verify specifics (pricing, plan gates, hook names, class signatures) against current docs before relying on them.

**2026-06-29**: By **Soflyy** — also makers of **Oxygen** and **WP All Import**. WordPress.org slug `breakdance`. Positioned as the modern Oxygen successor: **Oxygen 6 is rebuilt on the Breakdance engine** and is included in the Oxygen lifetime license; Oxygen users were also given a (historically 1-year) Breakdance license. github: used the developer-docs repo (github.com/soflyy/breakdance-developer-docs) for frontmatter since the org exists and that's the canonical public dev resource.

**2026-06-29**: Breakdance is a **standalone visual builder, NOT a Gutenberg block plugin** (contrast with Spectra/Kadence/GenerateBlocks/Stackable). It has its own front-end editor, is **themeless by default** (replaces the theme), and stores page layouts in its **own post meta** (opaque) — NOT portable Gutenberg block markup. So there's no "block namespace" to author; you build in the editor and automate the *post* + *form delivery*, not the layout meta. Closest catalog comparison is **Beaver Builder** (also a standalone non-block builder with a PHP module API).

**2026-06-29**: Developer surface is genuinely rich for a builder — public **Form Actions API** (`Breakdance\Forms\Actions\Action` → `name()`/`slug()`/`run($form,$settings,$extra)`, register via `\Breakdance\Forms\Actions\registerAction()` on `init`; `$extra` = files/fields[id⇒value]/formId/postId/ip/referer/userAgent/userId), **Dynamic Data Field API** (StringField/ImageField/GalleryField/OembedField → data objects; `registerField()`), **Conditions API** (`breakdance_register_template_types_and_conditions` + `Breakdance\ConditionsAPI\register`, element_display only — query-builder + templating conditions "planned"), AI endpoint filters, form hooks, save-action filters (experimental), posts-list hooks, reusable dependencies, Menu/Animations JS APIs. **Always register on `init` guarded with function_exists/class_exists** (docs warn of file-loading race conditions).

**2026-06-29**: #1 form gotcha — **spam plugins CANNOT intercept the Email action**. OOPSpam's own docs state Breakdance doesn't let plugin devs intercept certain actions (email notifications), so even when spam is blocked from storage, the email still sends. Workaround: order the spam-check action ABOVE Store Submission + Email, or remove the Email action entirely and notify downstream via the Webhook action → Make/Zapier. Honeypot is OFF by default (must enable); reCAPTCHA is **v3 only** (no v2 checkbox).

**2026-06-29**: Breakdance AI is provider-swappable via `breakdance_ai_api_endpoint` + `breakdance_ai_model` (+ `breakdance_ai_enabled`). Can point at OpenRouter and an Anthropic Claude model (`anthropic/claude-3.5-sonnet`) or any OpenAI-compatible endpoint. **The WP-Admin AI Assistant settings UI does NOT reflect filter changes** — verify via the browser console + the provider's usage dashboard. The key always goes in the "OpenAI API Key" field regardless of provider.

**2026-06-29**: Pricing (best-effort) — **Free** (WordPress.org, ~80 elements); **Pro ~$199.99/yr** unlimited sites + unlimited domain activations (promo through early July), full ~145 elements + WooCommerce Builder + Form/Popup Builder + Global Blocks + Client Mode; **Pro + AI bundle ~$249.99**. **NO lifetime plan** (annual only) but a **price-lock guarantee** at renewal; 60-day money-back. This is a differentiator vs Bricks ($599 lifetime) / Divi ($249 lifetime) — don't promise a one-time license.

**2026-06-29**: Performance is the headline pitch — blank page ~45 KB vs Elementor ~576 KB, conditional asset loading, jQuery-independent, themeless. But multiple reviews/guides converge: **slow Breakdance sites are misuse, not the builder** (layout nesting, Dynamic Data loops, unoptimized images, no caching). Audit those + theme/host first. No native A/B testing / heatmaps / analytics / hosted REST API.

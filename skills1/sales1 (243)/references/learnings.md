**2026-06-13**: API re-verified against live official docs — corrected several drifts. Rules use a structured `condition` (conditionalOperator/aiInstructions/static) + required `actions` array, NOT a flat `instructions` string, and there is no `automate` field; create/replace require name+condition+actions(min 1). Analytics path is `/stats/by-period` (not `/stats?period=`); NEW `/stats/response-time` endpoint added; the previously-listed `/group-emails` endpoint does NOT exist in the live OpenAPI. 15 ActionType values documented (incl. SEND_EMAIL/REPLY/FORWARD/ARCHIVE/MARK_SPAM/MOVE_FOLDER/DIGEST/CALL_WEBHOOK); `CALL_WEBHOOK` is an outbound rule action (gated by NEXT_PUBLIC_WEBHOOK_ACTION_ENABLED on self-hosted) — its signing scheme is undocumented (left UNVERIFIED). Pricing: $18/$28/$42 are MONTHLY per-user; annual is $14.40/$22.40/$35.28 (save 10/20/16%). GitHub ~11.2K stars. Microsoft Teams setup doc now live (DM assistant chat). Auth scheme confirmed `API-Key` header (OpenAPI ApiKeyAuth); base URL `https://www.getinboxzero.com/api/v1`. Rate limits and pagination still undocumented (UNVERIFIED).

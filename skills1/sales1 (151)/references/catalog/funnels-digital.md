Built on Laravel + Vue.js; **not a Merchant of Record** (you own tax). Developer surface: **two API flavors over the same engine, each split into a public Shop API and a protected Admin API** — **REST** (`composer require bagisto/rest-api`; `/api/shop/...`, `/api/admin/...`; Swagger at `/api/shop/documentation` + `/api/admin/documentation`) and **GraphQL** (`/api/graphql`, playground `/api/graphiql`; built on Laravel Lighthouse). Auth = public **`X-STOREFRONT-KEY`** (`pk_storefront_...`, generated at install or `php artisan bagisto-api:generate-key`) on Shop calls + **Laravel Sanctum bearer token** (`Authorization: Bearer 1|...`) on customer/admin routes; guests get a **cart token** (`POST /api/shop/cart-tokens`). Optional headers `X-Locale`/`X-Channel`/`X-Currency`. **REST pagination** `?page=&per_page=` (max 50) with `X-Total-Count`/`X-Page`/`X-Per-Page`/`X-Total-Pages` headers; **GraphQL** is Relay cursors (`first`/`after` + `pageInfo`). A **legacy standalone `bagisto/graphql-api` (Mobikul) package** uses a different `/graphql` endpoint with **JWT** + an **`x-app-secret-key`** header (configured via `JWT_TTL`/`MOBIKUL_API_KEY`) — don't mix its headers with the unified API. **No native outbound webhooks in core** — react to a **Laravel event** (e.g. `checkout.order.save.after`) in a listener and make the outbound HTTP call yourself (queue it; you own retries/signing/logging), poll `GET /api/admin/orders`, or add a community webhook package. Money is a **decimal string in the store currency** (e.g. `"29.9900"`), not cents. **Engine is free (MIT)**; **Bagisto Cloud** sells managed hosting in **Starter** and **Pro** tiers (Pro adds a higher uptime SLA + advanced support; public monthly prices aren't listed — verify live). Self-host needs **PHP/Laravel + MySQL/MariaDB + Redis + a queue worker**. Common footguns: **`APP_URL` mismatch → broken images / HTTPS mixed-content** (fix `APP_URL`, `php artisan optimize:clear`, `storage:link`), **extreme slowness on fresh installs** until caches/Redis/queue are configured (**bundle-product price calculation is a known slow path** on category pages — `php artisan optimize`), and **install permission errors** ("Impossible to create the root directory") on `storage/`/`bootstrap/cache/`.

**2026-04-03**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift fixed: CRUD base URL is `https://services.adroll.com/api/v1/` (was `api.nextroll.com`); PAT auth uses `Authorization: Token` + an `apikey` query param (NOT `Bearer`); CRUD endpoints are action/RPC-style (`/campaign/create`, `/adgroup/edit`…) not REST collections; GraphQL Reporting is `POST https://app.adroll.com/reporting/api/v1/query` (GraphiQL at app.adroll.com/reporting/graphiql), not `/report/graphql`; S2S is `POST https://srv.adroll.com/api?advertisable={eid}` with Server Access Tokens (SATs from account manager), not `/track/convert`; rate limit is a **default quota of 100 requests per service per day**, not ~60-120/min; NEW APIs added — Geotargeting API, Site Traffic Revealer (JS firmographic), Pixel JavaScript API. No webhooks (confirmed). Pricing restructured: official page now shows Self-Service (pay-as-you-go, $5/day min spend, $10/day min budget) vs Managed Services (Advanced Package, annual, contact sales); the flat "Marketing & Ads Plus $36/mo" tier is no longer named on the official page — third-party Starter ~$36 / Growth ~$67 figures left UNVERIFIED. Sources: https://apidocs.nextroll.com/guides/get-started.html, https://apidocs.nextroll.com/index.html, https://apidocs.nextroll.com/graphql-reporting-api/reference.html, https://apidocs.nextroll.com/server-to-server-api/reference.html, https://apidocs.nextroll.com/crud-api/reference.html, https://apidocs.nextroll.com/audience-api/overview.html, https://www.adroll.com/pricing.

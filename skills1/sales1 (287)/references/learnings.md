**2026-06-13**: API re-verified against live official docs — significant drift. (1) Reporting API moved from legacy v1 Mavrck `api.mavrck.co` to v2 at `reporting.api.later.com` (v1 deprecating ~6 months); documented endpoints now exist (`GET /v2/instances`, `/v2/instances/performance(-over-time)`, `/v2/campaigns(/performance)`, `/v2/platforms/performance`, `/v2/platforms/return-on-investment`, `/v2/creators/performance`, `/v2/posts/performance`); `POST /oauth/token` returns `{jwt}`, Bearer auth, tokens expire 12h per dev docs (help-center walkthrough still says 24h); rate limit 120 req/min/IP with `X-Ratelimit-Limit`/`X-Ratelimit-Window` + 429; `ANL_00xxx` RFC-9457 problem+json errors; cursor/page pagination; dedicated docs at docs.reporting.api.later.com with downloadable OpenAPI + a docs-search MCP (`@Latermedia/reporting-api-docs`); still no webhooks, no scheduling/content API. (2) Pricing changed: top tier renamed Advanced→Scale; monthly list now Starter $25 / Growth $50 / Scale $110 (annual $18.75/$37.50/$82.50, 25% off / 3 months free); Growth now 2 social sets + 180 posts/profile (was 3 sets/150); Scale 6 sets/unlimited; users 1/2/4; AI credits 5/50/100; analytics history 3mo/1yr/2yr; single-profile best-time now on Starter, advanced analytics (benchmarking/brand health/brand mentions) Scale-only. UNVERIFIED: free-plan existence (official pricing page WebFetch said no free plan / 14-day trial only, one 2026 third party claimed a Free tier) — left out.

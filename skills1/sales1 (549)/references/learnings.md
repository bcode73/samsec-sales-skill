**2026-04-22**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — SIGNIFICANT DRIFT. Pricing fully restructured: old Standard $10/hr + Premium $22/seat+$5/hr replaced by Pay As You Go $10/hr (no API), Core $25/mo (5 hrs), Advanced $50/mo (20 hrs, Most Popular), Pro $80/mo (40 hrs), Enterprise; overage $10/hr on all subs. API gate changed from "Premium+" to "available to all paying subscribers" (403 says "upgrade to Core or higher") — Pay-As-You-Go has no API. NEW: per-request `callback_url` on POST /media gives completion callbacks on ALL API plans (the old "no completion webhook, must poll" claim was wrong); dashboard Webhooks (Transcription/Translation finished, Label/Folder change) stay Enterprise-only and are HMAC-SHA256 signed via X-Webhook-Signature. NEW endpoints: PUT/DELETE /media/{id}, PUT /media/{id}/transcript(+/split), POST /media/{id}/media_exports + GET /media_exports/{id}, batch_summarizations, GET /summarizations/{id}, POST/PUT /users, GET/DELETE /media/{id}/shares, transcript.srt/.vtt/.json path forms; new POST /media params folder_id/keywords/custom_data/callback_url. NEW MCP server at https://api.sonix.ai/mcp (OAuth 2.1, separate from REST keys; read-only tools list_media/read_transcript/export_transcript/get_account_info). Documented rate limits exist only for OAuth endpoints (token 120/min/IP, registration 30/hr/IP); main REST endpoints still undocumented. Languages now 80+ in API table (marketing "54+"). Sources: https://sonix.ai/docs/api, https://sonix.ai/pricing, https://sonix.ai/api.

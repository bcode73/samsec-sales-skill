**2026-05-04**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — pricing rose and tiers were renamed (Essential $139→$169, Advanced $249→$299, Pro $399→$499, the "Agency $599" tier is now "Business $749", Enterprise $950→$1,299+); keyword/mention/user limits also increased (Essential 10kw/15k, Advanced 15kw/50k, Pro 25kw/100k, Business 40+kw/200k+; Advanced+ now Unlimited users). API access is now Pro/Business/Enterprise (the API gate is Pro at $499). NEW: v2 docs document two token types — User API Tokens (change when password changes) and Account Access Tokens (configurable expiry, default 30 days). Bearer 1-hour expiry, refresh-token flow, read-only nature, /api/mentions+aggregation+mentioners+top-keywords+demographics+top-countries+top-languages endpoints, channel IDs, and no-webhook/no-MCP all UNCHANGED. CAVEAT: the 100 req/min rate limit is only stated in the deprecated v1 article; the official v2 article says endpoints are "subject to rate limiting" with no published number.

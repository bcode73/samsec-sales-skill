**2026-03-30**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — resolved the three biggest gaps: base URL is `https://api.openwebninja.com/{api-name}/{endpoint}`, direct-portal auth is the `x-api-key` header (RapidAPI still uses `X-RapidAPI-Key`), and confirmed endpoint paths + the previously-unknown Social Links Search endpoint (`/social-links-search/search-social-links`). Website Contacts Scraper uses `query` (not `domain`) and batches up to 20 comma-separated domains, with extra social fields (tiktok/snapchat/github/youtube/pinterest). Email Search filter param is `email_domain`. Real-Time Web Search caps at 100 results/request (500 total via pagination), param `q`. JSearch is at `/jsearch/search-v2` with a 200-req free tier (and the current page no longer states a "200M+ listings" count — treated as unverified marketing). Web Unblocker has DIFFERENT/higher quotas (Free 100, Pro 50K, Ultra 250K, Mega 1M, PAYG $0.001/use) and JS-rendered requests cost 5 credits each. Pricing ladder (Free/Pro $25/Ultra $75/Mega $150/PAYG) UNCHANGED but overage is now explicit (~$0.003/$0.002/$0.001 per extra request); Local Business Data bills per object returned. No webhooks (request/response only) — UNCHANGED.

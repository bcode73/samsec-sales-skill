API: added base URL https://api.modash.io/v1/ and concrete endpoints (POST /v1/{platform}/search, /interests, /locations, /brands; POST /collaborations/posts + /summary at 0.2 credit each; ~0.01 credit/influencer found); search pagination uses a `page` param. Reframed product structure — API has TWO lines (Discovery, Raw); AI Search, Collaborations, Lookalikes are Discovery API sections, not separate products. UNCHANGED: version 1.5.0, Bearer/access_token auth, Discovery $16,200/yr (3,000 credits/mo), Raw $10,000/yr (40,000 req/mo), no webhooks, rate limits not publicly documented (429 + exponential backoff).

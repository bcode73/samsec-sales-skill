**2026-06-27**: Research baseline — platform overview, API surface, webhook/Zapier events, and pricing captured from live sources on this date. ⚠️ **The marketing site `viral-loops.com` returned 403 to automated fetches and the G2 pricing page + the specific developer-docs webhook page returned 403/404** — research assembled from the knowledge base (`documentation.viral-loops.com`), the Zapier app, and comparison articles; re-verify specifics in-account. Key facts: Viral Loops is a **referral & viral-marketing campaign builder** (templates: referral, pre-launch waitlist, giveaway/sweepstakes, milestone referral, ambassador, leaderboard, refer-a-friend) — **campaign-scoped**. API base `https://app.viral-loops.com/api/v3/`, auth via a per-campaign **`publicToken`** (from campaign install settings; a separate private/apiToken may exist for some ops — verify); core endpoint **`POST /api/v3/campaign/participant`** (register/upsert a participant; pass a `referrer` code to credit the referral), plus leaderboard + convert + reward endpoints (exact paths JS-rendered — confirm). **Webhooks** (Campaign Wizard) + **two-way Zapier** with 4 triggers (New Participant, New Referral Count, Participant Converted, Reward Redeemed) and a Create-Participant action; Make/Pipedream too. **No documented webhook HMAC** — secret URL + re-verify via GET before paying out; dedupe on (email, referralCountTotal) since count events repeat. Identity is email. Pricing (best-effort): Build ~$49/mo, Accelerate ~$229/mo, Enterprise custom; scales by participants; white-label + Concierge managed service on upper tiers. GitHub org `viralloops` (12 repos). No MCP. Notifications are email-only/basic (ReferralHero/UpViral stronger on SMS/automation/A-B testing). Viral referral/giveaway campaigns attract fraud (fake/disposable signups) — validate before rewarding. Its own affiliate partner program is agency/contact-based (no public commission rates).

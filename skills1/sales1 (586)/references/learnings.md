**2026-06-13**: API re-verified against live official docs — significant drift corrected. Base URL is `https://syften.com/api/0.0` (not `/api/v1`); all endpoints are POST-only (`/items/get` limit default 100/max 500, `/filters/get`, `/filters/set` which REPLACES all filters, `/settings/get`, `/info/get`) — there is no REST `/mentions` resource or per-filter CRUD. AI verdict is `item.analysis.accept` (bool) plus `score`/`sentiment`/`excerpt`/`suggested_reply`/`rejection_reason`, not `ai_verdict`/`ai_confidence`; source is `item.backend`, link is `item.item_url`. Webhook body is a JSON ARRAY of item objects (not a wrapped event); 2xx to ack; retries up to 48h with 5-min min backoff up to 12h, invalid URLs skipped; no documented HMAC. NEW: MCP server at `https://syften.com/mcp` (PRO only). Pricing is USD not EUR ($19.95/$39.95/$99.95); archive retention 7 days / 1 month / unlimited; X/Twitter and YouTube are paid add-ons on Standard+ (exact add-on prices unpublished — UNVERIFIED). Native Zapier trigger name not confirmed in docs (UNVERIFIED) — Pro users route via webhook → Catch Hook. Discord delivery claimed by third parties only (UNVERIFIED). Sources: https://syften.com/documentation, https://syften.com/pricing, https://github.com/syften/syften-examples.

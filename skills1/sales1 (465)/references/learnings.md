**2026-06-13**: API re-verified against live official docs — confirmed Ads API base URL https://ads-api.reddit.com/api/v3 (docs at /docs/v3/), OAuth2 Bearer with scopes adsread/adsedit/adsconversions and token endpoint https://www.reddit.com/api/v1/access_token (added to reference); added rate-limit detail (HTTP 429 + X-RateLimit-Remaining/X-RateLimit-Reset headers, no Retry-After); added the real CAPI endpoint POST https://ads-api.reddit.com/api/v2.0/conversions/events/{PIXEL_ID} with Bearer conversion access token; corrected Pixel/CAPI event names to Reddit's actual taxonomy (Page Visit / View Content / Add to Cart / Add to Wishlist / Purchase / Lead / Sign Up / Search / Custom — not "PageView"); pricing unchanged (auction-based, $5/day minimum, no platform/setup fee, no tiers).

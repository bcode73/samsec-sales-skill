**2026-06-13**: API re-verified against live official docs — corrected several drifts: public/published apps are now capped at up to 500,000 requests/day (was documented as "unlimited"); added the two missing rate-limit Reset headers (X-Ratelimit-App-Global-Minute-Reset, -Day-Reset); documented webhook HMAC-SHA1 signing via Sm-Apikey + Sm-Signature headers keyed with `api_key&api_secret` plus the full callback payload (filter_type/filter_id/event_id/object_type/object_id/event_datetime/resources) — previously undocumented; free Basic plan response limit corrected 40→25 responses per survey; collectors_write scope now requires a paid plan except for weblink collectors; added Canada datacenter base URL https://api.surveymonkey.ca/v3/. USD pricing for Standard/Advantage/Premier left unchanged — official page renders region-dependent (EUR) and third-party blogs disagree ($39 vs $99 Standard), so dollar figures are UNVERIFIED.

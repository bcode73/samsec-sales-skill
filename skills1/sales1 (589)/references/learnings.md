**2026-06-13**: API re-verified against live official docs — current REST API version is now 3.29 (Tableau Cloud June 2026 / Server 2026.2), not 3.28; fixed version + version-mapping table (2026.2 = 3.29, added 3.25/3.26/3.27 rows) and bumped URL examples. Added new 3.29 method groups: Recycle Bin Methods, Bridge Methods (client/pool/domain management), and per-site Tableau MCP Configuration. Corrected Tableau Cloud limits: there is NO fixed 10GB extract cap — site storage is 1 TB (Standard) / 5 TB (Enterprise/Tableau+/Advanced Management), individual workbook/data source/flow suggested limit is 25 GB, and a view querying an extract can use up to 20 GB memory; removed the stale "25GB/Creator, 5GB/Explorer" per-role storage figures. Noted Tableau Cloud now documents REST API concurrency limits that return HTTP 429 (specific per-endpoint numbers not published). Pricing UNCHANGED (Standard Creator $75 / Explorer $42 / Viewer $15; Enterprise $115/$70/$35, annual billing). Auth UNCHANGED (PAT/Connected App JWT/UAT/username-password; 240-min token; X-Tableau-Auth; PAT 15-day-inactivity Cloud / 1-yr Server); UATs noted as introduced in 2025.3. Could NOT verify on a directly-readable official page: a specific Trusted Authentication (Trusted Tickets) end-of-life date, and exact 429 concurrency thresholds — left unchanged.

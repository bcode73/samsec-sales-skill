**2026-06-13**: API re-verified against live official docs — significant drift. PRICING up to $79/$159/$319/mo (annual-billed; ~20% higher monthly) and AI Visibility prompts up to 50/200/300 (was 10/100/200); new per-plan "Reddit accounts" axis (1/3/unlimited) and a new Agency tier (from $1,000/mo). NOTE: the pricing page's prose/FAQ still show stale $59/$149/$299 and 10/100/200 — the cards + JSON-LD are authoritative. Campaign counts conflict on-page (cards say 3/3 for Growth/Pro, JSON-LD+prose say 5/10) so kept 1/5/10. API: Agent API now documents all 19 endpoints (was ~8) incl. /agent/subreddits/{name}/about, /comments, /wiki, /wiki/{page}, /widgets, /traffic; /agent/posts/batch, /agent/posts/{subreddit}/{id}/comments + /duplicates; /agent/users/{username}/posts + /comments. Corrected RESPONSE SHAPES — /agent/me returns {ok, credits:{used,remaining,limit}} (not authenticated/credits_remaining/plan); subreddit search uses display_name + NO relevance_score; domain mentions returns a FLAT array of post objects (not {mentions:[...]}); user profile splits link_karma/comment_karma + no post_history. Credit tiers corrected: search=3, feeds=2, lookups=1, wiki/duplicates/batch/domain-mentions=5. Usage headers X-Credits-Used/Remaining/Limit; 429 body {"statusCode":429,"message":"Too many requests"}; limit query param max 100 default 25. NEW AEO API (/v1/aeo/*, Pro plan only, returns 402 below Pro) — 25 endpoints for AI-visibility/citations/sources/brands/visibility data. CLI: auth login takes key inline, auth whoami/status/logout, group aliases r/u/d, --mode agent/human. Rate limits 60/min·1000/hr UNCHANGED; still no webhooks/Zapier/Make/MCP (read-only GET-only).

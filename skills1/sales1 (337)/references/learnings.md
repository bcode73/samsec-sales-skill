**2026-04-17**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — added NEW `GET /v1/meetings/{id}/insights` endpoint (KPI/talk-time/themes, 204 for pre-Dec-2024 meetings), documented rate limits (Free/Pro 100 req+10 uploads/day, Business/Enterprise 100 req+10 uploads/min), filled in webhook spec (two events `File analyzed successfully` w/ meeting_id + `File analyzed failed`, `X-MG-Signature` HMAC SHA-256 of raw body, up to 3 attempts/200-empty-body ack), corrected `/v1/upload` to take a `download_url` body (not multipart), added `/v1/meetings` pagination (`limit` max 500 + `cursor`), and updated MCP (Cloud endpoint `https://mcp.meetgeek.ai/mcp`, Local `@meetgeek/mcp-server` npm; the old `meetgeekai/meetgeek-mcp-server` GitHub link is no longer cited by docs). Pricing unchanged (Free $0/3hr, Pro $9.99/20hr, Business $17/unlimited, Enterprise custom). Voice-agents tier left UNVERIFIED (pricing page implied Enterprise-only, third parties say Pro+ — conflicting).

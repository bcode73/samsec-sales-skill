Pricing unchanged (Starter $14 / Productive $24 / Business $36, 30-day trial, no free plan); API still gated to Productive ("must be subscribed to the Productive plan to generate API tokens"). UNVERIFIED: pricing-page comparison table gave conflicting signals on whether Rules/Integrations are available on Starter — left the Productive-gate framing for Integrations/API unchanged (docs confirm API gate), did not edit the Rules gating. Webhooks unchanged (X-Hook-Signature HMAC-SHA256, 15s timeout, 5 retries/8min, auto-disable after 50+ consecutive failures).

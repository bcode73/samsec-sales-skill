**2026-04-01**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — drift found and fixed: webhook endpoints moved from `/v4/automations/hooks` to `/v4/webhooks` (v3→v4 change); 7 new webhook events documented (link_click, product_purchase, tag_add, tag_remove, purchase.purchase_create, custom_field.field_created/field_deleted/field_value_updated) plus per-event required params; OAuth rate limit is 600 req/60s vs 120 for API key; API key passes via `X-Kit-Api-Key` header (not query param); bulk + purchase-create endpoints require OAuth; list-subscribers is cursor-paginated (`before`/`after`/`per_page`, default 500/max 1000) with no `page` param, plus new include/slim/include_total_count params; remove-tag also has a by-email variant `DELETE /v4/tags/{tag_id}/subscribers`. Commerce transaction fee is 3.5% + $0.30 per txn (≈0.6% Kit + 2.9% Stripe), all plans incl. free — corrected from the old bare "0.6%". UNVERIFIED: free-plan subscriber cap (official pricing page is ambiguous — 1,000 next to price slider vs "Up to 10,000" in comparison table; 2026 third-party reviews say 10,000 — left as-is); OAuth authorize/token URLs not re-confirmed (left as-is).

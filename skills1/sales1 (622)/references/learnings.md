**2026-05-10**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — auth/base-URL/rate-limits unchanged, but response schema drifted: evidence_strength is now an object {volume,urgency,specificity} (was a flat float), market_metrics is now {competition_level,monetization_potential,opportunity_score} (was {post_count,recency_score} — post_count moved to top-level), pagination moved into a meta object {total,limit,offset,has_more}, new idea fields id/tagline/categories/updated_at; /v1/ideas gained keywords/min_validation_score/created_after/created_before/sort params (default sort = opportunity score); /v1/ideas/search gained mode=text|semantic (semantic Pro-only) + relevance score; /v1/ideas/:id/posts gained a limit param (default 10, max 5 free/100 pro) and its post objects use id/title/content/platform/url/created_at (NOT post_id/source/subreddit/score/num_comments); /v1/categories returns {category,count}; error schema is {error:{code,message}} with 401/404/429/500; anonymous tier max-offset is N/A not 100; no X-RateLimit-* headers documented.

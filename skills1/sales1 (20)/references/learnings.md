**2026-06-27**: Research baseline — platform docs, REST API v3 (`https://api.ahrefs.com/v3/`, Bearer API key from Account → API keys, owners/admins only, ≤1,000 keys with 1-yr expiry; OAuth for Ahrefs Connect apps), official MCP server, pricing, and credit/unit model captured from live sources on this date. Re-verify before relying. Key facts: **API v2 was fully discontinued 2025-11-01** — build only on v3. **API-units cost model**: min 50 units/request, scales with rows × fields; Rank Tracker/Management/Public + free test queries don't consume units; conserve with `select` (fields), small `limit` (rows), `batch-analysis`, and monitor via `/subscription-info/limits-and-usage`. **API units are included on Lite/Standard/Advanced for light use; heavy/production needs a paid API subscription (~$500–$10k/mo) or Enterprise.** Endpoint groups: Site Explorer (backlinks, organic-keywords, domain-rating, metrics), Keywords Explorer, Rank Tracker, Site Audit, Batch Analysis. **Official MCP server** `github.com/ahrefs/ahrefs-mcp-server` (hosted; Claude/ChatGPT/Cursor; **Lite plan+**; draws on the same API units). No event webhooks (read/research API only; pull not push). Pricing (best-effort): Starter $29 / Lite $129 ($108 annual, 500 credits/mo, monthly-only rank updates) / Standard $249 / Advanced $449 / Enterprise $1,499+. **Credit system** on Starter/Lite (1 credit per report). Add-ons: Brand Radar $199 (AI visibility), AI Content Helper $99, Report Builder $99. **No free trial. No affiliate program** (Ahrefs deliberately doesn't run one). Terminology: Domain Rating (DR), URL Rating (UR), Ahrefs Rank. GitHub org `ahrefs` (170 repos). Top complaints: credit caps/overage fees, expensive add-ons, and an aggressive "suspicious activity" anti-abuse system that throttles legit users within their limits.

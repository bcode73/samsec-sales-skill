**2026-04-26**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — API surface UNCHANGED (OAuth2 client-credentials at accounts.bliro.io/oauth/token, audience https://api.bliro.io, scope org:calls:read, GET /v3/calls, Bliro-Signature HMAC-SHA256, TLS 1.2/1.3, webhook deactivated-by-default). THREE corrections applied: (1) PRICING RESTRUCTURED — official pricing page + help article now show a sales-led 3-tier model Standard / For Revenue Teams / Enterprise with NO public euro prices and NO public free tier (user minimums 20/10/50); the old Free / Professional €49 / Unlimited €89 figures are gone from all official Bliro pages (only third-party aggregators still cite them) — treat euro numbers as unverified. (2) PLAN GATE CHANGED — API + Webhook Access are now BUNDLED with CRM in the "For Revenue Teams" plan ("Includes everything in Standard, plus: CRM integration ... Bliro API and Webhook Access"), not a separate higher "Unlimited" tier above CRM. (3) WEBHOOK SIGNING BUG FIXED — Bliro signs `${timestamp}.${JSON.stringify(payload.callData)}` (the inner callData object ONLY), not the raw HTTP body; the prior Python sample signed the full body and would never validate. Could not obtain current official euro pricing (sales-led) — left as unverified, did not substitute third-party numbers. Sources: https://help.bliro.io/en/articles/10329784-api-access, https://help.bliro.io/en/articles/10628092-receive-bliro-events-in-your-webhook-endpoint, https://www.bliro.io/en/pricing, https://help.bliro.io/en/articles/9720840-what-is-bliro-s-pricing.

**2026-03-28**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — corrected: OAuth token endpoint to `https://auth.seismic.com/tenants/{tenant}/connect/token` (was `/oauth2/token`); rate limits to tiered 10/30/60/600-per-60s with `X-Seismic-Remaining-Calls`/`X-Seismic-Total-Calls` headers (was flat ~100/min + `Retry-After`); webhook event names to PascalCase `...V1`/`...V2` (e.g. `LivesendCreatedV1`, `DSRCreatedV1`, `LiveDocCompletedV2`, `UserCreatedV1`) with `x-seismic-signature`/`x-seismic-signature-old` HMAC-SHA256, 10s/2xx, 26-attempt retry (was dot-style `livesend.viewed` etc.); LiveDocs to Document Generator run endpoint `POST /integration/v2/teamsites/{teamsiteId}/livedocVersions/{libraryContentVersionId}` + separate `livedocs-express/v2` host (no `/livedocs/generate`-`/process`); Reporting API is ETL/table-based ≥24h refresh, not submit-and-poll; added sandbox host `api-sandbox.seismic.com` + per-route versioning + portal moved to `/seismicsoftware/`; merger date corrected to 2026-02-12 (was "late 2025"), both platforms supported until close. Pricing unchanged (still custom enterprise quote). Unverified/left as-is: exact OAuth scope strings, simplified library/workspace/SCIM/programs/meetings/search endpoint paths (real routes are teamsite-scoped).

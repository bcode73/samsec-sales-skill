**2026-06-13**: API re-verified against live official docs — base URL (api.tor.app/developer), Bearer auth, and 1,000 req/min rate limit UNCHANGED; pricing tiers (Lite $9.99/300min, Pro $19.99/2400, Team $30/3000, bulk plans) UNCHANGED; corrected webhook endpoints to /integrations/webhooks with webhookType (body for update, query for delete) and confirmed no HMAC signing; corrected export params (format→export_type, include_speaker_names/include_timestamps/merge_same_speaker_segments/is_single_paragraph, paragraph_size 1/2/4/8); corrected Get Summary to GET /transcription/summary?order_id=, Rename File to PUT /files/{order_id} body file_name, and speaker recognition to annotations/profiles (no recognize_speakers endpoint); added documented endpoints Update Transcription Content (PUT /files/{order_id}/content), Transcribe via URL (POST /transcription/url), Transcribe Meeting (POST /transcription/meeting), AI Chat (POST /ai_chat/knowledgebases/{kb}/sessions/{session}); custom vocabulary now takes a words array (max 1000, 6 words/phrase); segments include VoiceStart/VoiceEnd (ms) and Speaker SPK_1; free tier now "Free — 90 Minutes".

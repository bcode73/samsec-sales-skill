**2026-05-02**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — pricing ($25/$65/$105 + Copilot $20 / Smart QA $20 / Smart CSAT $10 / bundle $25), per-plan rate limits (50/100/200 rpm), OAuth partner 120 rpm, pagination, and base URL all UNCHANGED. NEW: 4th token feature type "MCP server" (Claude/ChatGPT); 600 rpm app-server connection limit; Zapier is the only customer-installed integration counting against the customer limit; Autopilot now priced usage-based starting at $0.05/conversation. CHANGED: webhook signing + retries are now fully documented — app webhooks use header x-front-signature (HMAC-SHA256 over x-front-request-timestamp + ":" + raw body), retry up to 3x on error/429/500/408/timeout (5s window) then Front disables the webhook; rule webhooks use X-Front-Signature (HMAC-SHA1 base64 of body) and do NOT retry. ~14 documented app event types (inbound_received, outbound_sent, conversation_moved, assignee_changed, tag_added, etc.). Sources: https://front.com/pricing, https://dev.frontapp.com/docs/authentication, https://dev.frontapp.com/docs/rate-limiting, https://dev.frontapp.com/docs/pagination, https://dev.frontapp.com/docs/application-webhooks, https://dev.frontapp.com/docs/rule-webhooks.

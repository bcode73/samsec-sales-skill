**2026-06-13**: API re-verified against live official docs — base URL (`https://server.smartlead.ai/api/v1/`) and `api_key` query-param auth UNCHANGED, but corrected several drifts: rate limit is 60 req/min per key (default, adjustable) with ~10 req/2s burst and 429+`retry_after`/exponential-backoff (was wrongly "wait 60s"); plan tier names are now Base/Pro/Unlimited Smart/Unlimited Prime (not Basic/Custom); webhooks are campaign-scoped at `/campaigns/{id}/webhooks` (not global `/webhooks`) with real event identifiers EMAIL_SENT/FIRST_EMAIL_SENT/EMAIL_OPEN/EMAIL_LINK_CLICK/EMAIL_REPLY/EMAIL_BOUNCE/LEAD_UNSUBSCRIBED/LEAD_CATEGORY_UPDATED/CAMPAIGN_STATUS_CHANGED/UNTRACKED_REPLIES/MANUAL_STEP_REACHED/EMAIL_ACCOUNT_DISCONNECTED/LINKEDIN_DISCONNECTED (the old LEAD_REPLIED/LEAD_INTERESTED/EMAIL_OPENED/EMAIL_CLICKED/EMAIL_BOUNCED names were wrong); lead "status" is actually customizable categories set via `POST /campaigns/{id}/leads/{lead_id}/category` (`category_id`,`pause_lead`), not a fixed enum or `/leads/{id}/status`; add-leads is `lead_list` max 400/request.

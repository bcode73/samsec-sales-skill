**2026-04-23**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — base URL `https://api.attention.tech/v2` and `Authorization`-header Bearer auth UNCHANGED; OpenAPI version bumped 1.6.0→1.8.0 (now 65 paths). Endpoint renames: `/calendar/events`→`/calendar_events/{user_uuid}`, `/createDeck`→`/create_deck`, `/connection-report`→`/connectionReport`, `/usage-report`→`/usageReport`, `/scim/ServiceProviderConfig`→`/scim/ServiceProviderConfigs`; `/scorecards/summary` is now POST (was GET); `/scorecards` gained POST. Many NEW endpoints added (CRM query, field-configurations, labels, knowledge-base, super-agent, conversation crm/confirm + linked-crm-records + by-external-id + title/labels, integration-workflows, library/folders, chats). MCP server is now an official HOSTED remote server at `https://api.attention.tech/mcp` (HTTP Streamable, OAuth 2.1 + DCR or API-Key-JWT Bearer) — replaces the GitHub-only self-host framing. No formal webhook event system in the API (only an optional `callback_url` on super-agent). Pricing ($59/$149/$399) still third-party-only, unchanged, left caveated. Sources: https://docs.attention.com/api-reference/openapi.json, https://docs.attention.com/api-authentication, https://docs.attention.com/mcp/authentication, https://docs.attention.com/llms.txt.

**2026-05-16**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — minor drift found. Pricing now lists 4 named tiers including a concrete Advanced tier ($2,988/mo, 50M requests, 1,000 zones, 100 advertisers, 5 users) where the skill previously had only "Advanced/Enterprise / Custom"; API Access + Programmatic are included on Advanced/Enterprise, add-on on Essentials/Standard (Essentials $179/mo, Standard $682/mo unchanged). JSON ad API callback param is `click_mode=callback` (underscore), not `clickmode`. `accupixel_url` is only returned when AccuPixel is enabled in settings (if disabled, impression is tracked on response and the field is omitted) — corrected the prior "MUST be called" absolute. Reports API confirmed: default limit 10, offset pagination, response carries top-level `has_more` and rows may include responses/eCPC/eCPA. MCP server unchanged install (`claude mcp add adbutler -- npx -y @adbutler/mcp-server`), now advertised as 36 tools. adbutler-php SDK repo is archived; node + mobile SDKs still present. No webhooks documented (unchanged). Exact add-on dollar amounts not authoritatively published — left unverified. Sources: https://www.adbutler.com/pricing.html, https://www.adbutler.com/help/article/subscription-add-on-optional, https://www.adbutler.com/help/article/accessing-adbutler-api, https://www.adbutler.com/help/article/json-ad-tag-api, https://www.adbutler.com/help/article/reports-api, https://help.adbutler.com/mcp/, https://github.com/adbutler.

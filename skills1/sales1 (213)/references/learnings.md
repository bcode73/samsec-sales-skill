**2026-06-29**: Standout feature vs other block plugins is the **API Connector** — a no-code consumer of external REST APIs, Google Sheet/CSV, and **LLM APIs (OpenAI-style chat + streaming)**, in two modes: **server-side** (runs on the WP server, response stored in the block, Application-Password Basic auth, placeholders `{{FORM}}`/`{{INCREMENT}}`/`{{RANDOM}}`/`{{USER_META}}`) and **client-side** (browser fetch, placeholders `{{VALUE}}`/`{{COOKIE}}`/`{{STORAGE}}`/`{{ATTR}}`/`{{SESSION_ID}}`/`{{FORMDATA}}`). **Client-side keys are PUBLIC** — never put a secret key client-side; use server-side or a proxy. Client-side fires a `GSPB_API_RESPONSE` JS event with `{ resultElem, responseData }`.

**2026-06-29**: AI Helpers use **your own** API key — requests go directly to the chosen third-party provider, no Greenshift subscription/credits needed. Plus a Figma converter, HTML-source→blocks, and any-webpage/website→Greenshift converters (GreenLight PRO).

**2026-06-29**: Top support-forum pain points (cover in Troubleshooting/Gotchas): (1) **no styles on frontend** = inline-CSS save hitting host/DB field-length limits on huge pages → switch CSS management to save inline within blocks + re-save; (2) **animations blank in the Gutenberg editor** but fine on the front end (expected for some scroll/GSAP effects); (3) **backend "too many requests"/editor freeze** (heavy pages, Button block freeze-on-update, many editor API calls); (4) **HTTP→HTTPS breaks fonts/icons** (old http static files) → re-upload static files + confirm HTTPS site URL; (5) **duplicate synced patterns share style IDs** → duplicate the ungrouped copy and delete the original to regenerate unique IDs; (6) plugin compatibility (a version of Accessibility Checker broke the Video Advanced block).

**2026-06-29**: Developer surface = WordPress core REST API (blocks are **`greenshift-blocks/`-namespaced** in `post_content`, `GSPB`-prefixed classes) + the API Connector (external/AI APIs) + the `GSPB_API_RESPONSE` JS event. **No hosted Greenshift API, no outbound webhook, no core form block, no Zapier app, no native A/B testing/heatmaps.** Performance pitch is ~2 KB base styles + conditional assets + no jQuery, but heavy GSAP/3D/Lottie block counts + per-page CSS still cost — audit theme/images/scripts first for CWV.

**2026-06-29**: Security — a historical advisory **CVE-2023-6636** affected older versions; recommend staying current and avoiding nulled/pirated builds. (There are public "greenshift-activator" repos that bypass licensing — do not recommend; they're a malware/abuse vector.)

**2026-06-13**: API re-verified against live official docs — no drift in core API (Advertiser API base `papi.buysellads.com`, `?key=` auth, 4 endpoints/params/fields, no pagination, UTC, error codes; Ad Serving API base/params/fields + test zone `CVADC53U`; `_bsa` JS methods; Buttondown-only ESP integration; Zapier triggers; commission 25%/15%, wire $500/$35 all UNCHANGED). Added NEW details now in docs: empty Ad Serving response carries a top-level `zonekey` field; email `/ads/get/ids/` supports semicolon-batched multi-zone and is not per-email-sent (same ad to all subscribers per send); Optimize has a client-side `window.optimize` JS API (events `rewardedSlotReady`/`rewardedSlotGranted`/`rewardedSlotClosed` via addEventListener, `pushAll`/refresh advanced functions, SPA `queue.push`, identity hashing via `window.optimizeIdentityHashes` + Web Crypto); fuller payout schedule (PayPal $20 min 2-3 days up to 2/mo, bank check $50 min 1/mo, wire $500/$35 weekly, funds available 30 days after purchase); docs site publishes an `llms.txt`.

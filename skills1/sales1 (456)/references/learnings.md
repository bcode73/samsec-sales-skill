**2026-04-02**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift fixed. The Identity Resolution API is now "APIs V2": base URL is `https://api.rb2b.com/api/v1` (was `https://api.rb2b.com/v1`), auth header is `Api-Key` (was `x-api-key`), all endpoints are POST with a JSON body (was GET with query params), inputs are snake_case (`ip_address`, `email`, `md5`, `linkedin_slug`), credit cost is per-endpoint 1–4 (business_profile=2, mobile_phone=3, linkedin_to_business_profile=4) not a flat 1, and the rate limit is 50 req/sec per endpoint (was "not documented"). New/changed endpoints: ip_to_maid + hem_to_maid + email_to_maid are LIVE (MAID was "coming soon"), only reverse MAID→HEM remains "coming soon"; added linkedin_to_mobile_phone, business-profile and best-LinkedIn variants, and a /credits balance endpoint. There is now an official MCP server `@rb2b/rb2b-apis-mcp` (npx -y @rb2b/rb2b-apis-mcp init; key in ~/.rb2b/config.json). Pixel pricing: Free plan dropped all person-level contact data (Jan 2026); credit-per-visitor model (1 credit per unique visitor per 30 days, no rollover, Jan 14 2026 restructure doubled limits); coverage now 15-20% US on Starter/Pro and 35-45% on Pro+; Starter = LinkedIn URLs only, business emails start at Pro; overage ~$0.45 (Starter) / ~$0.25 (Pro/Pro+); extra domains ~$99/mo. API credit ladder updated ($9/100, $149/3K, $999/50K, $4,999/500K, $49,999/5.25M). Pixel webhook payload/signing still not publicly documented (left as estimated). Sources: https://www.rb2b.com/apis, https://www.npmjs.com/package/@rb2b/rb2b-apis-mcp, https://registry.npmjs.org/@rb2b/rb2b-apis-mcp, https://support.rb2b.com/en/articles/12579420-rb2b-apis-rb2b-s-api-partner-program, https://support.rb2b.com/en/articles/10442291-changelog, https://www.rb2b.com/pricing.

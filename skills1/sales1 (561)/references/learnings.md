**2026-06-29**: Research baseline — platform docs (spreecommerce.org/docs + llms.txt), API reference (introduction, platform/authentication, webhook subscribers/events), the GitHub README (spree/spree, v5.5.x), the 5.5 announcement, and MCP/agent-skills posts captured from live sources on this date. Key facts:
- Open-source **BSD-3-Clause**, **API-first headless commerce on Ruby on Rails**. The Rails counterpart to Medusa (Node/TS), Saleor (Python/GraphQL), Bagisto (Laravel/PHP), Sylius (Symfony/PHP). Stack: Rails + PostgreSQL + Redis/Sidekiq + MeiliSearch + a Next.js 16/React 19/Tailwind storefront.
- **Four API layers, three auth schemes:** Store API (`/api/v3/store`, **publishable key `pk_xxx`** + per-cart **order token**); Platform API (`/api/v2/platform`, **OAuth2 client-credentials** at `POST {store}/spree_oauth/token` with `grant_type=client_credentials`/`client_id`/`client_secret`/`scope=admin` → `Authorization: Bearer`); Admin API (`/api/v3/admin`, **open-sourced in 5.5**, **scoped API keys**, own TS SDK + CLI); legacy Storefront API v2 (`/api/v2/storefront`, JSON:API, since 3.7).
- **OpenAPI 3.0 specs:** admin.yaml / store.yaml / platform.yaml / storefront.yaml / oauth.yml / openapi.json. Official TS SDK `@spree/sdk`. No first-party core GraphQL.
- **Native outbound webhooks** ("Webhooks 2.0" + Event Bus). Subscribe via Platform API `/api/v2/platform/webhooks/subscribers` (`subscriptions: ["*"]` or specific names). Deliveries logged as Webhook Events (name, response_code, success, execution_time, request_errors). Confirmed event example: `order.canceled` (pattern `<resource>.<action>`).
- **Pricing/editions:** Community Edition free (self-host, no per-sale fee; ~$200–2,000/mo cloud hosting). Enterprise Edition custom (5–6 figures/yr; SSO SAML/OIDC, encryption-at-rest, advanced B2B/marketplace/multi-tenant, managed hosting, premium support). **Not a Merchant of Record** — you own tax.
- **5.5 AI-agent surface (headline for the Claude Code maker audience):** 25 agent skills (`github.com/spree/agent-skills`, best-effort `npx skills add spree/agent-skills`), **docs MCP server `https://spreecommerce.org/docs/mcp`** (add as a Claude Code Connector), an Admin API CLI for agents, generated CLAUDE.md/AGENTS.md, llms.txt. Skills cut token use ~90% vs scanning Rails source.
- **Top pain points (Step 1b):** (1) version-upgrade difficulty breaking customizations + version-locked extensions — Spree rewrote extensions to be universal and 5.5 ships an automatic upgrade tool; keep customizations as thin decorators/overrides, don't fork core. (2) self-hosting complexity (real Rails ops: Postgres + Redis + Sidekiq + MeiliSearch; "needs a programmer"). (3) opaque/large DB schema + heavy customization burden. (4) community-only support on CE.

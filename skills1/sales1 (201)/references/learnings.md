**2026-05-13**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — base URL `https://api.getaccept.com/v1`, `/auth` token body, and Enterprise API gate all unchanged; corrected major drift: (1) auth also supports OAuth2 authorization-code flow (`app.getaccept.com/oauth2/authorize` + `/oauth2/token`) plus `/refresh` & `/revoke`, not just token auth; (2) NATIVE webhooks exist via `/subscriptions` REST hooks with 15 document events (created/sent/viewed/reviewed/signed/approved/expired/rejected/downloaded/printed/forwarded/partially_signed/commented/hardbounced/imported) — old reference wrongly said native webhooks were undocumented / Zapier-or-Make-only; webhooks are NOT HMAC-signed (verify via fixed sending IPs + custom headers per help center); (3) pagination is `offset`/`limit` (+ filter/sort_by/sort_order/showteam/showall/external_id on documents); (4) rate-limit state exposed via `X-Rate-Limit-Limit/Remaining/Reset` headers (no published number); (5) error body is `{error, description, status}` not `{error, message}`; (6) added ~40 previously-missing endpoints (documents/{id}/send, /status, /recipients, /forward, /reminders, /revisions, /preview, /log, /pages, /pricing-tables, templates, email/templates, users, teams, folders, notifications, uploads, videos). Pricing unchanged: eSign $25, Professional $49, Enterprise custom (official page) — third-party Capterra lists Enterprise $79 but official page says custom, left as custom. Sources: https://github.com/getaccept/openapi/blob/master/openapi.json, https://www.getaccept.com/api, https://www.getaccept.com/pricing, https://help.getaccept.com/en/articles/8094998-webhook-settings.

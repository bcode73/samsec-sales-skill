**2026-06-13**: API re-verified against live official docs — base URL (`{account}.api-us1.com/api/3/`, with docs caveat that api-us1 isn't guaranteed), `Api-Token` auth, 5 req/sec rate limit, contact/sync upsert, deal create, and pricing (Starter $15 / Plus $49 / Pro $79 / Enterprise $145 annual @1K; 10x/10x/12x/15x send multipliers; Pipelines CRM add-on $68/mo; Nov 2025 all-contacts-count billing for new accounts) all UNCHANGED. Fixes applied: corrected the OAuth claim (v3 REST API is Api-Token only — OAuth2 exists solely in App Studio for CX-App→external-service auth, not for calling the AC API); added newly-documented 429 headers `RateLimit-Limit`/`RateLimit-Remaining` alongside `Retry-After`; added webhook event `deal_tasktype_add` (now 24 events); fixed platform-guide typo `contactSync` → `contact/sync`. Sources: https://developers.activecampaign.com/reference/authentication.md, https://developers.activecampaign.com/reference/url.md, https://developers.activecampaign.com/reference/rate-limits.md, https://developers.activecampaign.com/reference/webhooks.md, https://developers.activecampaign.com/reference/sync-a-contacts-data.md, https://developers.activecampaign.com/reference/create-a-deal-new.md, https://www.activecampaign.com/pricing.

**2026-03-27**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift fixed. Rate limit is NOT 100 req/min; it is a quota-units-per-hour model (per-operation cost, scaled by plan/seats) with a separate monthly recipient-add cap (errors `limit_reached` / `exceeds_monthly_recipients`). Webhook events corrected to Clicked/Opened/Replied/MessageSent/LeadCreated/LeadStatusChanged; push payload is a minimal `{resource_url}` you must fetch (no HMAC; respond 200 to ack, 410 to unsubscribe). No `markAsLost` endpoint — use `leads/close` with `status:"lost"`; added `leads/create`; lead status is `closed` (="Won"). Activity endpoints renamed to `created-leads`/`lead-assignments`/`lead-status-changes` (no `bounces`/`leadCatcher` endpoints — bounces come via `activity/replies` type filter). Auth also supports `Authorization: Basic <base64 apiKey>` header (curl `-u "key:"`). Recipients `add` takes `addresses`/`listOfEmails`/`csvData` (max 5,000/campaign); `get` and `leads/get` support email lookup. Added `campaigns/exportStatus`. OAuth: authorize at app.mailshake.com/oauth/, token+refresh at /2017-04-01/token, scopes campaign-read/campaign-write. Official docs moved to api-docs.mailshake.com. Pricing (mailshake.com/pricing): Starter $29/mo ($25 annual), Email Outreach $49/mo ($45), Sales Engagement $99/mo ($85), Agency custom — skill files quote no tier prices so nothing to correct there. Sources: https://api-docs.mailshake.com/, https://docs.mailshake.com/article/260-api-limits, https://mailshake.com/pricing/

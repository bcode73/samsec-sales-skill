# Informly — Learnings

Accumulated platform knowledge. Append new findings with a dated line.

**2026-07-05**: Research baseline. Informly (informly.ai; product at validator.informly.ai) is an AI
startup-idea validation + pre-launch report generator — "validate your business idea instantly with the
help of AI." One freeform idea description → a single 75+ page PDF (page count marketed inconsistently
as 45+/75+). Viability score + ~11 reports (idea validation, MVP roadmap, landing-page blueprint,
marketing strategy, sales blueprint, competitive positioning, fundraising navigator, pivot playbook,
customer discovery, pitch deck, growth/launch plan), framed Ideate → Validate → Plan (aka
Validate/Launch/Grow), 23 topics. Grounded with real-time Google Search. AI business-advisor chat
(marketing/finance/sales/tech/fundraising/ops) in the dashboard. Founders Prageeth & Edisa Silva
(Melbourne; company registered in Anguilla). ~4,290 entrepreneurs claimed.

**2026-07-05**: Pricing is **$29.99 per report, one-time — NO subscription, NO credits**. Each idea is a
separate purchase; post-pivot re-runs cost again (7-day satisfaction guarantee allows a capped
refund + re-generation, ~2 uses). Free = sample reports only. Stripe payments; PDF-only export. Advertises
a ~30% affiliate program ("limited time").

**2026-07-05**: **No documented public API, no webhooks, no Zapier/Make, no MCP.** UI-only tool that
outputs a PDF only. Get data out by downloading + parsing the PDF.

**2026-07-05**: Independent-review criticism (ReadySetLaunch /compare/informly/review): single freeform
text input with no structured questioning, no independent scoring rubric, action plans "assume Go, not
No-Go," inconsistent page-count claims (45+ vs 75+), thin third-party review presence (few Reddit/
Trustpilot/G2 reviews), only ~11 public ratings after ~1 year. → Positioned in the skill as a
directional gut check + starter-asset/document generator, with the go/no-go pushed to a real demand
test via /sales-idea-validation.

**2026-07-05**: **Domain note — the backlog listed `informly.io`, which does NOT resolve (ENOTFOUND).**
The real domain is **informly.ai** and the app is at **validator.informly.ai**. Homepage WebFetch of
`.io` failed; used `validator.informly.ai` + the ReadySetLaunch review + AI-tool directory listings.

**2026-07-05**: Adjacent scan (ReadySetLaunch /compare review named competitors) surfaced new
idea-validation tools NOT yet cataloged → added to backlog: **IdeaCheck** (ideacheck.ai — multi-module
AI validation, reports from $2.99 + monthly Starter credits), **CheckMyIdea** (checkmyidea-ia.com —
single-shot + best-seller evaluation packages), **SaaSlidator** (AI project-idea validation +
monetization + build guidance). RebeccAi, DimeADozen, BuildOrNot, Preuve already backlogged;
ValidatorAI/IdeaProof already skills.

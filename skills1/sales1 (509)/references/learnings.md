**2026-06-13**: API re-verified against live official docs (docs.seamless.ai) — base URL `https://api.seamless.ai/api/client/v1`, `Token` header, OAuth Bearer, and search/research/poll paths all UNCHANGED. Corrected drift: rate limit is **60 req/min per endpoint, org-shared** (was 100/60s); webhook events are `contact-researched`/`company-researched` configured at Settings→Webhooks with an `x-seamless-webhook-secret` shared-secret header (was unsigned `contact.research.completed`); poll statuses are `queued/researching/done/error/missing/duplicate/not found/contact-already-researched/No license or credits available` (was processing/completed/failed); research body adds `isJobChange`/`skipDeduplicationCheck` + email/LinkedIn-URL identifiers, response `{success, requestIds}`; webhook/poll payloads use `fullName`/`phones`/`linkedInProfileUrl`/`apiResearchId`; search filters are flat camelCase keys, `supplementalData` has `isMore/total/perPage/nextToken`; `GET /contacts` requires ISO8601 startDate/endDate + adds page/limit(max 500). NEW: MCP server at `https://mcp.seamless.ai/mcp` (54 tools/11 domains, OAuth 2.1 or API key); public API now on **every plan incl. Free** (2026-05-11 release), Universal-Credits-only, drawing from plan balance — so API is NOT Enterprise-gated.

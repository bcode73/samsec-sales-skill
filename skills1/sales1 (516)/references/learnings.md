**2026-06-13**: API re-verified against live official docs — subscriber/group updates use PUT (not PATCH); group add/remove is POST/DELETE /subscribers/{id}/groups with the group ID in the body (not in the path); rate limits ARE now documented (per-account per-minute, X-RateLimit-Limit/-Remaining/-Reset headers, 429 + Retry-After); webhooks expanded from 2 to 8 topics (subscribers/new|updated|unsubscribed, groups/new|new-subscriber|unsubscribed, campaigns/new, bounces/new) and now carry a per-webhook Signing Secret for HMAC payload verification (exact signature header + algorithm not published — left UNVERIFIED); added documented transactional endpoint POST /v2/message/send (from/to/subject/html). Pricing unchanged: Free Forever 2,500 subs / 15K emails, Standard from $7/mo, 12x/24x email multipliers (Standard/Pro live price values render client-side and could not be re-confirmed verbatim).

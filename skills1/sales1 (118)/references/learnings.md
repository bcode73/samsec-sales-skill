**2026-05-07**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — significant drift. Auth is `X-API-Key` (ct_live_ keys), NOT `Authorization: Bearer`; endpoints are GET `/api-posts` and GET `/api-intelligence` (Share of Voice), NOT `/v1/mentions` + `/v1/generate` (no `/v1/` prefix); rate limit is a single 5,000 req/day with hourly reset and `X-RateLimit-*` headers (NOT per-plan 1K/5K); documented error codes added (PLAN_NO_API_ACCESS, MISSING_KEYWORD, MISSING_QUERY_ID, RATE_LIMIT_EXCEEDED, etc.); `/api-posts` response schema rewritten (ai_score 1–10, ai_reason, intent, urgency, buying_stage, suggested_play, etc.) replacing the old intent_score/sentiment fields. Pricing: NEW Free tier ($0, 1 keyword, Reddit only); Starter $29→$39 with 3→4 keywords; Pro $99 and Advanced $199 unchanged. API access still gated to Pro+. The `/generate` content endpoint and webhook push remain only on the marketing /api-integration page (absent from the technical /api-documentation page) and webhook payload/signing stay undocumented — kept but flagged as unverified. Sources: https://www.communitytracker.ai/api-documentation, https://www.communitytracker.ai/api-integration, https://www.communitytracker.ai/pricing, https://www.communitytracker.ai/.

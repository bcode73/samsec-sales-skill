**2026-04-15**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — confirmed drift and fixed: (1) pricing shifted from vCore-based to USAGE-BASED — Integration Starter/Advanced now bill on Mule Flows + Mule Messages + throughput (GB/yr), "shown in Access Management instead of vCores," flows counted Max-Concurrent; (2) Runtime Manager API (hybrid/api/v1) manages ON-PREM apps ONLY — added separate CloudHub API (cloudhub/api) for CH 1.0 and Application Manager API (amc/application-manager/api/v2) for CH 2.0; (3) MQ Broker base URL is region-specific (mq-us-east-1.anypoint.mulesoft.com); (4) AI surface updated — Agent Fabric (GA, Discover/Govern/Orchestrate/Observe), Omni Gateway (MCP + A2A), AI Gateway/LLM Governance GA, MCP Connector, "MuleSoft Vibes" replaces "Dev Agent" naming. Unchanged/confirmed: OAuth2 token endpoint accounts/api/v2/oauth2/token + client_credentials, /accounts/login still valid (not deprecated), MQ Admin rate limit 50 TPM, Stats 10/200 TPM + 5-10min latency, Gold/Platinum/Titanium support tiers.

**2026-06-27**: Research baseline — platform docs, the webhook/Event-Subscription/REST surface, pricing, and the affiliate program captured from live sources on this date. Re-verify before relying. Key facts: ThriveCart is a **checkout/cart platform for creators** (digital products/courses/subscriptions) sold as a **lifetime (one-time) license**. Integration is **event-driven**: **standard webhooks** (one URL gets ALL account events) vs the **Event Subscription API** (subscribe to specific event types). Events: `order.success`, `order.refund`, `order.failed`, `order.subscription_payment` (rebill), `order.subscription_cancelled/paused/resumed`, upsell/downsell/bump, `affiliate.commission_earned`/payout, abandoned-cart. **Auth:** API tokens (Settings → API & webhooks → API tokens) for your account, **OAuth** for third-party apps; **rate limit 60 req/min per account**; official **PHP SDK**; reference at `apidocs.thrivecart.com`. **No HMAC** — webhook authenticity is validated via a shared **`thrivecart_secret`** you configure; reject mismatches; dedupe on `order_id`; match offers by **product id** not name. Pricing (best-effort, changed 2025): Standard **$495 one-time**, Pro+ **$790 one-time + $295/yr from year 2**, Ultimate **$985 + $295/yr**. **Pro+ gates the creator essentials: affiliate center, sales tax, custom checkout domain, dunning, advanced reporting** — Standard lacks them, so "lifetime" is misleading for serious creators. **ThriveCart Learn / Learn+ are DEPRECATED** (no new features) → **ThriveAcademy** is the replacement; don't build new course delivery on Learn. **No download/link protection** — delivered file links can be freely shared; gate access in your own app/LMS off the purchase webhook. Own affiliate program: **50% per sale** (~$350+ per referral on $495–$790 licenses), 2nd-tier available, **PayPal payout only**, 15K+ affiliates. GitHub org `thrivecart` (22 repos). No MCP server. History: instability after ownership changes (downtime, Stripe connectivity, support gaps) — reportedly stabilized by 2026, but reviews still cite billing bugs.

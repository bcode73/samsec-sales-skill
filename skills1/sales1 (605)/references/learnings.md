**2026-04-16**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — no drift in regional base URLs (all 5 confirmed), 120s timeout, userinfo-only Subscription-Locator exemption, camelCase/Epoch, OAuth2+Bearer, or tier limits (Basic 5 / Premium 15 / Hybrid 25-per-pack). Corrected one wrong claim: Subscription Locator is a URL PATH parameter `{subscriptionLocator}` (pass `0` for token's org), NOT a header. Added newly-verified facts: OAuth access token ≤8h + refresh token 7 days; concrete documented endpoints (POST .../apps push new+updated app via multipart artifact/manifest.json/overrides, POST .../apps/{appId}/stop, GET .../status, GET/PUT .../endpoints, GET .../instances/{id}/monitoring/metrics/resource with `since`, PUT/DELETE .../pin); Hybrid plan bundles API Management up to 100k QPM; no platform-level webhooks/HMAC (eventing via Flogo triggers).

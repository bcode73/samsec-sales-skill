# Appendix: Templates

Templates live in `/templates` as reusable documents you adapt to your own business, distinct from worksheets, which are one-time reflective exercises.

| Template | Introduced in | Purpose |
|---|---|---|
| `proposal-template.md` | Module 7: Present the Offer | The seven-part structure behind every proposal in this book: confirmed problem, value stack, recommended package, inclusions, scope boundary, price, next step |
| `customer-persona-template.md` | Module 4: Learn the Customer | One completed persona per stakeholder in a buying committee, not one per deal |
| `follow-up-email-template.md` | Module 10: Nurture Relationships | Six-week and six-month check-ins, an anniversary note, a referral ask, and a loop-closing message |

Adapt the wording in every template to how you actually talk. A template that reads like a corporate memo undoes the trust Module 3 spent effort building.

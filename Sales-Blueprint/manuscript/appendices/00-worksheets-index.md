# Appendix: Worksheets

Every worksheet lives as its own file in `/worksheets`, so it can be printed or filled in independently of the book. This index lists them in the order they appear.

| # | Worksheet | Introduced in | Use it to |
|---|---|---|---|
| 1 | `01-myth-audit.md` | Module 1: The Truth About Sales | Diagnose which of the four myths shaped a deal you lost |
| 2 | `02-buying-committee-map.md` | Module 2: How Customers Really Buy | Map every stakeholder who could delay or block a decision |
| 3 | `03-trust-audit.md` | Module 3: Build Trust | Prepare competence, reliability, and candour signals before a first meeting |
| 4 | `04-discovery-questions.md` | Module 4: Learn the Customer | Run the three discovery questions and map the buying committee |
| 5 | `05-problem-diagnosis.md` | Module 5: Understand the Problem | Separate a stated symptom from its real cause and quantify the cost |
| 6 | `06-value-stack-builder.md` | Module 6: Establish Value | Build a value stack of distinct, buyer-confirmed outcomes |
| 7 | `07-offer-builder.md` | Module 7: Present the Offer | Rebuild a proposal around one recommendation, a scope boundary, and a next step |
| 8 | `08-objection-resolution.md` | Module 8: Remove Doubt | Sort a hesitation and build a specific resolution for it |
| 9 | `09-action-friction-audit.md` | Module 9: Inspire Action | Diagnose friction on a stalled, agreed deal and shrink the next step |
| 10 | `10-nurture-cadence-planner.md` | Module 10: Nurture Relationships | Plan genuine, no-pitch touchpoints for a past customer |
| 11 | `11-referral-ask-builder.md` | Module 11: Turn Customers into Advocates | Prepare a specific referral ask and a loop-closing message |
| 12 | `12-digital-signal-audit.md` | Module 12: Digital Selling | Map digital equivalents of in-person trust and discovery signals |
| 13 | `13-pipeline-rebuild.md` | Module 13: Sales Systems | Rebuild a pipeline around the nine Blueprint letters |
| 14 | `14-thirty-day-rollout-planner.md` | Module 14: The 30-Day Sales Blueprint | Plan a four-week rollout of the full framework |

Use them in order the first time through the book; after that, open whichever one matches the stage your current deal is actually at.

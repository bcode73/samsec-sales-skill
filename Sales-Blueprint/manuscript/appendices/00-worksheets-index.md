# Appendix: Worksheets

Every worksheet is collected in full, in this order, in the worksheets section at the back of this book, so you can fill one in without flipping back to the chapter that introduced it. This index lists them in the order they appear.

| # | Worksheet | Introduced in | Use it to |
|---|---|---|---|
| 1 | Myth Audit | Module 1: The Truth About Sales | Diagnose which of the four myths shaped a deal you lost |
| 2 | Buying Committee Map | Module 2: How Customers Really Buy | Map every stakeholder who could delay or block a decision |
| 3 | Trust Audit | Module 3: Build Trust | Prepare competence, reliability, and candour signals before a first meeting |
| 4 | Discovery Questions | Module 4: Learn the Customer | Run the three discovery questions and map the buying committee |
| 5 | Problem Diagnosis | Module 5: Understand the Problem | Separate a stated symptom from its real cause and quantify the cost |
| 6 | Value Stack Builder | Module 6: Establish Value | Build a value stack of distinct, buyer-confirmed outcomes |
| 7 | Offer Builder | Module 7: Present the Offer | Rebuild a proposal around one recommendation, a scope boundary, and a next step |
| 8 | Objection Resolution | Module 8: Remove Doubt | Sort a hesitation and build a specific resolution for it |
| 9 | Action Friction Audit | Module 9: Inspire Action | Diagnose friction on a stalled, agreed deal and shrink the next step |
| 10 | Nurture Cadence Planner | Module 10: Nurture Relationships | Plan genuine, no-pitch touchpoints for a past customer |
| 11 | Referral Ask Builder | Module 11: Turn Customers into Advocates | Prepare a specific referral ask and a loop-closing message |
| 12 | Digital Signal Audit | Module 12: Digital Selling | Map digital equivalents of in-person trust and discovery signals |
| 13 | Pipeline Rebuild | Module 13: Sales Systems | Rebuild a pipeline around the nine Blueprint letters |
| 14 | Thirty-Day Rollout Planner | Module 14: The 30-Day Sales Blueprint | Plan a four-week rollout of the full framework |

Use them in order the first time through the book; after that, open whichever one matches the stage your current deal is actually at.

# Worksheet 4: Discovery Questions

Use this on an active deal where you've already built some initial trust.

## Step 1: Ask the three questions

Record the buyer's answers in their own words, not your summary.

| Question | Their answer |
|---|---|
| Who else needs to be comfortable with this before it happens? | |
| What are you personally measured on this year? | |
| What would make this decision hard to defend to your board or team? | |

## Step 2: Map the committee

List everyone named in your answer to the first question above, plus anyone you already knew about.

| Name | Role | Contacted directly? |
|---|---|---|
| | | |
| | | |

## Step 3: Learn the organisation's decision process

Ask how they made a comparable decision before (even in a different category) and note:

- How long did it take?
- Who had to sign off?
- What almost made them choose differently?

## Step 4: Apply it forward

Compare your current proposal or pitch against what you learned in Steps 1 to 3. Does it speak to the personal stake you uncovered, or only to the generic business need? Revise one sentence of your pitch to reference something specific you learned in this conversation.

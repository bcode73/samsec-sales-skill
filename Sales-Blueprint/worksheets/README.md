# Worksheets

One Markdown file per exercise referenced in a module (e.g. `03-trust-audit.md`, `04-customer-persona-builder.md`, `06-value-stack-builder.md`). Each worksheet is self-contained and printable: a reader should be able to open a single worksheet file without needing the surrounding chapter to complete it, though it makes far more sense alongside the module that introduces it.

Populated during Phase 17 (Appendices) and as each Part Two/Three/Four module is drafted.

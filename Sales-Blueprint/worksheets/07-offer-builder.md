# Worksheet 7: Offer Builder

Use this to rebuild a proposal for an active deal that already has a confirmed value stack (Worksheet 6).

## Step 1: Pick the one recommended package

If your current template offers multiple equal options, choose the one you'd actually recommend to this buyer and describe it in one paragraph.

## Step 2: State what's included

List everything covered in the fixed price, in plain language.

## Step 3: Name what counts as a variation

List the specific things that would trigger extra cost or time, stated before the buyer has to ask.

## Step 4: Build the ladder, if you need one

If a genuine choice helps this buyer, define a reduced tier and an enhanced tier beneath and above your recommendation. Keep the recommendation visually and verbally the default.

| Tier | What changes | Price |
|---|---|---|
| Enhanced | | |
| Recommended | | |
| Reduced | | |

## Step 5: Write one specific next step

Replace any open-ended closing line with a specific, dated action needed from the buyer.

## Step 6: Apply it forward

Send the rebuilt proposal and note the buyer's first question. A question about the recommended option itself means the offer is doing its job; a question asking you to explain the difference between options means Step 1 needs another pass.

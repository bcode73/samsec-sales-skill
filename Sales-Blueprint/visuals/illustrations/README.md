# Illustrations

Original, non-diagrammatic artwork commissioned for the book — scene-setting imagery, part-divider art, and any conceptual illustration that isn't a data structure or process (that's what `../diagrams/` and `../charts/` are for). Each illustration's generation prompt lives in `../prompts/`; the rendered file is saved to `../exports/`.

Populated during Phase 18 (Visuals).

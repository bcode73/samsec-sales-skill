# Charts

Data-style visuals — figures with axes, curves, bars, or dashboard layouts, such as the Customer Lifetime Value curve and the Sales Dashboard mock-up. Distinct from `../diagrams/`, which covers process/structure diagrams (pyramids, funnels, flowcharts), and from `../illustrations/`, which covers non-data scene artwork. Prompts live in `../prompts/`; rendered output is saved to `../exports/`.

Populated during Phase 18 (Visuals).

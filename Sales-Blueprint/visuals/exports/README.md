# Visual Exports

Rendered PNG/SVG output of the diagrams, illustrations, charts, and icons defined elsewhere in `/visuals`. Nothing here is hand-authored — every file is a build output of a prompt (`../prompts/`) or a Mermaid source file (`../diagrams/`). Distinct from the top-level `/exports/`, which holds the compiled, reader-facing manuscript (DOCX/PDF/EPUB/print), not individual visual assets.

Populated during Phase 18 (Visuals), as each visual is finalised.

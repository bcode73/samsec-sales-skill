# Icons

Small supporting iconography used within callout boxes, worksheets, and templates (e.g. a tip icon, a warning icon, an exercise marker), kept consistent with the visual style defined in `BOOK_BIBLE.md` §7. Not used for anything that teaches a concept on its own; that belongs in `../diagrams/`, `../illustrations/`, or `../charts/`.

Populated during Phase 18 (Visuals).

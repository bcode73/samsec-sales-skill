# Visual Generation Prompts

Detailed prompts for premium, full-page graphics intended for external image generation (cover, part dividers, and the 15 signature diagrams in their polished form). One file per visual, each containing:

- **Purpose** — what it teaches and why it earns its place
- **Placement** — exact module/section it accompanies
- **Caption** — the exact caption line to run beneath it in the manuscript
- **Generation prompt** — the full, detailed prompt for producing the graphic

Distinct from `../diagrams/`, which holds the lightweight Mermaid versions that render directly inline in the Markdown manuscript. Rendered output of the prompts in this folder is saved to `../exports/`; commissioned scene-style artwork and data-style charts have their own homes in `../illustrations/` and `../charts/` respectively.

Populated during Phase 18 (Visual prompts and diagrams).

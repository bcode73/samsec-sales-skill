# Visual Prompt: Offer Builder

**Purpose:** Shows the four-part structure of a well-built offer, in a fixed order, so a reader can check their own proposal against it.

**Placement:** Module 7, Present the Offer, replacing `visuals/diagrams/figure-7.1-offer-builder.mmd`.

**Caption:** Figure 7.1: a well-built offer has four parts, in a fixed order.

**Generation prompt:**
A minimal horizontal four-step diagram on a warm cream background (#FBF9F4). Four equal-width pale teal (#E3EEEC) rounded rectangles in a row, connected by thin charcoal (#1B1F1E) arrows pointing left to right, each numbered 1 to 4 in a small deep teal (#0F3D3E) circle in the top corner. Labels in sentence case: "Recommended package," "What's included," "What counts as a variation," "One next step." One short italic sans-serif subtitle beneath each (recommended: "built from the confirmed value stack"; included: "stated plainly, not implied"; variation: "named before the buyer has to ask"; next step: "specific and dated, not open-ended"). Clean sans-serif typography, no gradients, no drop shadows, no icons. Landscape orientation.

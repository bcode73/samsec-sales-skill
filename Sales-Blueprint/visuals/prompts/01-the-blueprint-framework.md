# Visual Prompt: The Blueprint Framework

**Purpose:** The book's signature diagram. Establishes the nine-stage sequence the whole book teaches, so a reader can recall it from memory after seeing it once.

**Placement:** Front matter, "The Blueprint Framework" chapter, replacing the in-manuscript Mermaid version (`visuals/diagrams/figure-0.1-blueprint-framework.mmd`) in the print and premium digital editions.

**Caption:** Figure 0.1: the nine stages a buyer moves through on the way to a decision.

**Generation prompt:**
A minimal, premium business-consulting diagram on a warm cream background (#FBF9F4). Nine rounded rectangles arranged in a single gentle arc left to right, each containing one bold letter (B, L, U, E, P, R, I, N, T) above a short label in sentence case (Build trust, Learn the customer, Understand the problem, Establish value, Present the offer, Remove doubt, Inspire action, Nurture relationships, Turn customers into advocates). Each box filled in deep teal (#0F3D3E) with cream text. Thin connecting arrows in charcoal ink (#1B1F1E) link each box to the next in sequence. A subtle dotted arrow loops from the ninth box back to the first, labelled "referral restarts the cycle" in small italic sans-serif type. Clean sans-serif typography throughout, generous whitespace, no drop shadows, no gradients, no icons or illustrations beyond the shapes themselves. Landscape orientation suitable for a full-width page spread.

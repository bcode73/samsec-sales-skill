# Visual Prompt: Buying Psychology Wheel

**Purpose:** Shows that a buyer's stated problem is a mix of four distinct forces, so a reader diagnosing a problem checks for all four rather than stopping at the first one mentioned.

**Placement:** Module 5, Understand the Problem, replacing `visuals/diagrams/figure-5.1-buying-psychology-wheel.mmd`.

**Caption:** Figure 5.1: a buyer's stated problem is a mix of four forces. Missing any one means an incomplete diagnosis.

**Generation prompt:**
A minimal circular diagram on a warm cream background (#FBF9F4). A central charcoal (#1B1F1E) circle labelled "The stated problem" in cream text, with four pale teal (#E3EEEC) segments arranged evenly around it like spokes, each connected to the centre by a thin line and each containing a deep teal (#0F3D3E) label in sentence case: "Immediate irritation," "Quantifiable cost," "Risk of a wrong fix," "What success feels like." One short italic sans-serif line beneath each segment label (irritation: "what they notice day to day"; cost: "what leaving it unsolved is costing, in numbers"; risk: "what happens if the solution misses"; success: "the state they're actually trying to reach"). Clean, symmetrical, no gradients, no drop shadows, no decorative icons. Square orientation, generous margin.

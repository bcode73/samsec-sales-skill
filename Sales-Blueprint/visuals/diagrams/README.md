# Diagrams

Mermaid source for every in-manuscript figure, one `.mmd` file per diagram, named `figure-{module}.{sequence}-{slug}.mmd` (e.g. `figure-3.1-trust-pyramid.mmd`). These are the diagrams referenced directly from the module text and render inline in Markdown/GitHub — distinct from the premium full-page graphics specified in `../prompts/` and their commissioned counterparts in `../illustrations/` and `../charts/`.

Populated during Phase 18 (Visual prompts and diagrams), alongside the modules that reference them.

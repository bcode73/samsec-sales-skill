# Template: Proposal Structure

Introduced in Module 7 (Present the Offer). Use this structure after Worksheet 6 (value stack builder) is complete; do not start a proposal before the value stack exists.

## 1. The confirmed problem

One paragraph, in the buyer's own words and numbers, restating the diagnosis they already agreed to (see Worksheet 5). This is not new information to the buyer; it is proof you understood them correctly.

## 2. The value stack

List each distinct, itemised outcome from Worksheet 6, in the buyer's language, with the number or detail it connects to. Present this before any price appears.

## 3. The recommended package

Describe one clear, recommended solution. If a ladder is useful, show a reduced and an enhanced tier beneath and above it, with the recommendation visually and verbally the default (see Module 7's Pricing Ladder).

## 4. What's included

A plain list of everything covered by the fixed price.

## 5. What counts as a variation

A plain list of the specific things that would trigger extra cost or time. State this before the buyer has to ask.

## 6. Price

Only appears here, after the value stack and scope are already visible.

## 7. One next step

A single, specific, dated action needed from the buyer. Not "let me know what you think."

# PDF Export

Compiled PDF build of the manuscript. Generated output only, not edited by hand; regenerate with the pipeline in `/build` rather than editing this file directly.

**`sales-blueprint.pdf`**: the first sellable ebook version, built for direct sale on Selar. 186 pages at 6in x 9in: cover, table of contents, all front matter, all 14 modules with embedded diagrams, and the full appendices including every worksheet, template, and checklist in full (not just the index). No ISBN, no bleed, no print marks; this is a digital-only build. See `/build/README.md` for how it's produced and what's still rough about it (page numbers on the cover/divider pages, no PDF bookmarks).

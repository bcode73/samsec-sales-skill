# Exports

The compiled, reader-facing manuscript in each commercial output format. This is the only folder in the repository that represents the finished product rather than working material — everything here is generated from `/manuscript`, `/visuals`, and `/assets`, never edited by hand.

- **`docx/`** — Compiled manuscript, Word format
- **`pdf/`** — Compiled manuscript, PDF format
- **`epub/`** — Compiled manuscript, EPUB format
- **`print/`** — Print-ready, press-ready files (bleed, margins, colour profile applied)

Populated during Phase 20 (Export), after the final quality control pass (Phase 19) is complete.

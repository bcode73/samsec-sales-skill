# Assets

Brand and production material for the book as a commercial product, distinct from `/visuals`, which holds book-*content* artwork (diagrams, illustrations, charts that teach something inside a chapter). Nothing in this folder is manuscript content.

- **`logos/`:** SSO Publishing and Sales Blueprint logo marks, in the formats needed for covers, exports, and marketing.
- **`fonts/`:** Licensed typefaces used in layout and export, kept here so builds are reproducible without depending on machine-installed fonts.
- **`brand/`:** Colour palette definitions, cover art, and brand guidelines governing the visual identity described in `BOOK_BIBLE.md` §7.

Populated as cover design and production begin, alongside Phase 18 (Visuals) and Phase 20 (Export).
